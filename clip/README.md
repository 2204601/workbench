# Clip

メールアドレスや電話番号、住所、メールの署名など、よく入力する文字を登録しておき、ショートカット 1 つで呼び出して入力できるアプリです。コピーしたものの履歴も、同じ一覧から選べます。macOS（Apple Silicon）と Windows で動きます。

![screenshot](docs/screenshot.png)

## インストール

[Releases](https://github.com/2204601/workbench/releases?q=clip) から最新版をダウンロードしてください。

| OS | ファイル | 入れ方 |
| --- | --- | --- |
| macOS（Apple Silicon / M1 以降） | `Clip_<バージョン>_aarch64.dmg` | 開いて `Clip.app` を「アプリケーション」フォルダへドラッグ |
| Windows（64 ビット） | `Clip_<バージョン>_x64-setup.exe` | 実行してインストーラの指示に従う |

Intel Mac 向けの版は配布していません。

### 初回起動

署名（Apple Developer ID / Windows コード署名）なしのビルドなので、**初回インストール時だけ**警告が出ます。

- **macOS**: `.dmg` を開いて `Clip.app` を「アプリケーション」へコピー → 起動すると「開発元を検証できない」と出るので「完了」→ **システム設定 › プライバシーとセキュリティ** の下にある「このまま開く」を押します。
  ターミナルで `xattr -dr com.apple.quarantine /Applications/Clip.app` を実行しても構いません。
- **Windows**: `-setup.exe` を実行 → SmartScreen が出たら「詳細情報」→「実行」。

起動すると「スニペットと設定」のウィンドウが開きます。ここでよく使う文字を登録してください（下の「スニペットを登録する」）。

### macOS：自動で入力するための許可

選んだものを、それまで使っていたアプリにそのまま入力する（⌘V を代わりに押す）には、macOS の**アクセシビリティ**の許可が要ります。

1. ポップアップの上に出る「許可する…」か、「スニペットと設定」の「設定」にある「許可する…」を押す
2. **システム設定 › プライバシーとセキュリティ › アクセシビリティ** で Clip をオンにする

許可しないあいだは、選ぶとクリップボードにコピーされるだけなので、自分で ⌘V を押して貼り付けてください。

アップデートのあとで自動の入力が動かなくなったら（一覧では Clip がオンのままでも）、同じ画面で Clip を選んで「−」で一度外し、もう一度「許可する…」から許可し直してください。署名なしのビルドは、版が変わると macOS から別のアプリとして扱われるためです。

Windows では許可は要りません。

### ログイン時に起動

初めて起動したときに「ログイン時に起動」がオンになります。Clip は起動していないとコピーを履歴に残せないためです。メニューバー / タスクトレイのアイコンのメニューにある「ログイン時に起動」で、いつでもオン・オフできます（一度オフにすれば、勝手にオンに戻ることはありません）。ログイン時の起動では、ウィンドウは開かずにメニューバー / タスクトレイで待機します。

- macOS では、オンになったときに「バックグラウンド項目が追加されました」という通知が出ることがあります。**システム設定 › 一般 › ログイン項目** にも表示されます
- macOS で `.dmg` の中から直接起動しているとき（「アプリケーション」へコピーしていないとき）は、オンにしません

### アップデート

アプリ内で更新します。

- 起動から数秒後と、起動したままなら 1 日 1 回、新しいバージョンを確認します。あればダイアログで知らせます（「更新して再起動」で適用、「あとで」なら次の確認でまた知らせます）
- 手動で確認するには、メニューバー / タスクトレイのアイコンをクリック →「アップデートを確認…」
- スニペットと履歴はそのまま残ります

会社のネットワークなどでプロキシが必要な場合は、OS のプロキシ設定（自動プロキシ設定の PAC を含む）をそのまま使います。

## 使い方

### 呼び出して入力する

1. 入力したい場所（メールの本文、Web のフォーム、Excel のセルなど）にカーソルを置く
2. **Ctrl + Alt + C**（macOS は **⌃ Control + ⌥ Option + C**）を押す。画面の上のほうに一覧が出ます
3. 文字を打って絞り込み、**↑↓** で選んで **Enter**

選んだものが、元の場所にそのまま入力されます。一覧の上にはスニペット、その下にコピーの履歴（新しい順）が並びます。

| キー | 動作 |
| --- | --- |
| 文字を打つ | 絞り込み。名前と内容の両方から探します。全角 / 半角、大文字 / 小文字、カタカナ / ひらがなの違いは無視し、電話番号は「0312」のようにハイフンなしでも見つかります |
| ↑ ↓、Page Up / Page Down | 選ぶ |
| Enter | 入力する |
| ⌘ / Ctrl + 1 〜 9 | 上から 1 〜 9 番目をすぐ入力する（行の右に番号が出ています） |
| ⌘ / Ctrl + Enter | 入力せず、クリップボードにコピーだけする |
| ⌘ / Ctrl + S | 選んでいる履歴をスニペットにする |
| ⌘ / Ctrl + Delete（Backspace） | 選んでいる履歴を消す |
| ⌘ / Ctrl + , | スニペットと設定を開く |
| Esc | 絞り込みを消す。もう一度押すと閉じる |

マウスでも操作できます。行をクリックすると入力し、履歴の行に出るボタンでスニペットにしたり消したりできます。ほかの場所をクリックすると一覧は閉じます。

入力されるのは**書式なしの文字**だけです（太字や色は付きません）。また、入力のあとはクリップボードの中身が、入力した文字に置き換わります（それまでコピーしていたものは履歴に残っています）。

### スニペットを登録する

メニューバー / タスクトレイのアイコン →「スニペットと設定…」（またはポップアップ右上のボタン）で開くウィンドウで登録します。

- 「よく使う項目を追加」の **メールアドレス**・**電話番号**・**住所**・**メールの署名** などを押すと、その名前のスニペットができるので、内容を入れるだけです
- 「＋ 追加」で好きな名前のスニペットを作れます。名前を空にしておくと、内容の 1 行目が名前になります
- 内容には改行も入れられます（署名や定型の挨拶文など）
- 入力した内容はその場で保存されます
- ↑ ↓ ボタンで並び順を変えられます。ポップアップにもこの順で並びます
- 削除は「削除」を 2 回押します

コピーの履歴からも登録できます（ポップアップで履歴を選んで ⌘ / Ctrl + S）。

### 履歴

Clip が起動しているあいだにコピーした**テキスト**を記録します。

- 記録しないもの：パスワード管理ソフトなど、コピーするアプリが「履歴に残さない」印を付けたもの（macOS は nspasteboard.org の印、Windows は Win + V の履歴と同じ印）、ファイルのコピー、画像、10 万バイトを超える長い文字
- 同じ文字をもう一度コピーすると、重ならずに一番上へ移ります
- 「設定」で、残す件数（50 〜 500 件、既定は 200 件）と期間（1 日〜 1 年、既定は 30 日）を変えられます。超えた分は自動で消えます
- 記録を止めるには、メニューの「履歴を記録する」のチェックを外します（「設定」にもあります）
- すべて消すには、メニューの「履歴を消去…」

### ショートカットキーを変える

「スニペットと設定」の「設定」で、呼び出すキーを次から選べます。

| Windows | macOS | 注意 |
| --- | --- | --- |
| Ctrl + Alt + C（既定） | ⌃⌥C | |
| Ctrl + Alt + V | ⌃⌥V | Windows では Excel などの「形式を選択して貼り付け」が使えなくなります |
| Ctrl + Shift + Space | ⌃⇧Space | |
| Ctrl + Alt + Space | ⌃⌥Space | macOS では入力ソースの切り替えと重なることがあります |

ほかのアプリがすでに同じキーを使っていると、そのキーは使えません（「設定」に表示されます）。そのときは別のキーを選ぶか、メニューの「Clip を開く」から開いてください。

### メニューバー / タスクトレイのメニュー

| 項目 | 動作 |
| --- | --- |
| Clip を開く | ポップアップを出す（横に今のショートカットが出ます） |
| スニペットと設定… | 登録と設定のウィンドウを開く |
| 履歴を記録する | 履歴の記録のオン・オフ |
| 履歴を消去… | 履歴をすべて消す（スニペットは消えません） |
| ログイン時に起動 | オン・オフ |
| アップデートを確認… | 新しいバージョンを確認する |
| 終了 | Clip を終了する |

macOS では Dock にアイコンは出ません。メニューバーのアイコンから操作してください。Clip をもう一度起動すると（「アプリケーション」やスタートメニューから）、「スニペットと設定」のウィンドウが開きます。

### 知っておくとよいこと

- スニペットと履歴は、次の場所にそのまま（暗号化せずに）保存されます。履歴には、コピーしたものがそのまま入ります。人に見られたくないものをコピーしたら、履歴から消すか、記録を止めてください
  - macOS: `~/Library/Application Support/dev.workbench.clip/`
  - Windows: `%APPDATA%\dev.workbench.clip\`
- Clip がインターネットに接続するのは、アップデートの確認だけです。スニペットや履歴をどこかへ送ることはありません
- Windows で、管理者として実行しているアプリには自動で入力できません（Windows の制限）。そのときはコピーされているので Ctrl+V で貼り付けてください

### アンインストール

- **macOS**: メニューの「ログイン時に起動」をオフにしてから、「アプリケーション」フォルダの `Clip.app` をゴミ箱へ（オフにし忘れたときは `~/Library/LaunchAgents/Clip.plist` を削除）。アクセシビリティの一覧からも「−」で外してください
- **Windows**: 「設定」→「アプリ」から Clip をアンインストール

スニペットと履歴も消したい場合は、上の保存先のフォルダも削除してください。

## 開発

Tauri 2（Rust）＋ TypeScript（Vite、フレームワークなし）で作っています。

### 必要なもの

[Tauri の前提ツール](https://v2.tauri.app/start/prerequisites/)を入れてください。

- Rust（stable）
- Node.js 20 以上
- macOS: Xcode Command Line Tools
- Windows: Microsoft C++ Build Tools と WebView2（Windows 11 には最初から入っています）

### コマンド

```sh
cd clip
npm install
npm run tauri dev      # 開発モードで起動（画面の変更はすぐ反映されます）
npm run tauri build    # インストーラを作成（macOS は .app/.dmg、Windows は -setup.exe）
npm test               # Rust のテストと型チェック
npm run lint           # ESLint、cargo fmt --check、clippy（CI と同じ）
```

作成したインストーラは `src-tauri/target/release/bundle/` に出力されます。

`npm run tauri build` にはアプリ内アップデート用の署名鍵が要ります（`createUpdaterArtifacts` が有効なため）。鍵なしでインストーラだけ作るときは、更新ファイルを作らない設定を足します。

```sh
TAURI_SIGNING_PRIVATE_KEY="$(cat <秘密鍵のファイル>)" npm run tauri build
# 鍵なし
echo '{"bundle":{"createUpdaterArtifacts":false}}' > /tmp/no-updater.json
npm run tauri build -- --config /tmp/no-updater.json
```

開発モード（`npm run tauri dev`）では自動のアップデート確認はしません（トレイの「アップデートを確認…」は動きます）。「ログイン時に起動」も自動ではオンにしません。macOS のアクセシビリティの許可は、開発用のバイナリ（またはそれを起動したターミナル）に対して別に要ります。

Linux でもビルドとテストはできますが、クリップボードと自動の入力は動きません（Linux 向けには配布しません）。

### CI

`clip/` 以下か `.github/workflows/clip.yml` を変える PR を作ったとき（その後の push も含む）と、それが `main` にマージされたときに、GitHub Actions で macOS（Apple Silicon）と Windows のテストとビルドが走ります。PR のない作業ブランチへの push では走りません。作られたインストーラは、実行結果ページの Artifacts からダウンロードできます。

署名鍵の Secrets（下記）が使えないとき（フォークからの PR など）は、アップデート用のファイルを作らずにインストーラだけをビルドします。

### リリース手順

1. バージョンを上げる（3 か所とも同じ値にします）
   - `package.json` … `npm version <バージョン> --no-git-tag-version`（`package-lock.json` も更新されます）
   - `src-tauri/tauri.conf.json` の `version`
   - `src-tauri/Cargo.toml` の `version`（`Cargo.lock` は `cargo update -p clip` で更新）
2. [`CHANGELOG.md`](CHANGELOG.md) に `## <バージョン>` の節を書く。この節がそのままリリースの本文になります
3. PR を作って `main` にマージする
4. GitHub の Actions → **clip** → **Run workflow** で、ブランチ `main`、`release` にチェックを入れて実行する

ビルドが通ると `clip-v<バージョン>` のタグと Release が作られ、`.dmg` と `-setup.exe` が添付されます。`clip-v<バージョン>` のタグを直接 push しても同じ動きになります。

- 同じバージョンのタグがすでにある場合は失敗します（先にバージョンを上げてください）
- `CHANGELOG.md` に該当バージョンの節がない場合も失敗します
- アップデート用のファイル（署名）がない場合も失敗します（Secrets を確認してください）

### アプリ内アップデートの仕組み

インストール済みのアプリは `https://github.com/2204601/workbench/releases/download/clip-updater/latest.json` を見ます（`tauri.conf.json` の `plugins.updater.endpoints`）。このリポジトリには他のツールのリリースも並ぶため、`releases/latest` は使えません。そこでリリースのたびに、`clip-updater` という固定のリリース（プレリリース扱い）の `latest.json` を新しい版のものに置き換えています。**`clip-updater` のリリースとタグは消さないでください**（配布済みのアプリが更新を見つけられなくなります）。

更新ファイルの署名鍵は、Shelf・Renamer と同じ workbench の GitHub Actions の Secrets です（`TAURI_SIGNING_PRIVATE_KEY`、`TAURI_SIGNING_PRIVATE_KEY_PASSWORD`）。対応する公開鍵は `tauri.conf.json` の `plugins.updater.pubkey` です。
