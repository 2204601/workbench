# Changelog

リリースは GitHub Actions の clip ワークフローを `release` にチェックを入れて手動実行するか、`clip-v<バージョン>` のタグを push すると作成されます。本文はこのファイルの該当バージョンの節から取られます。

## 0.1.0

最初の版です。

### 変更点

- メールアドレスや電話番号、住所、署名などを「スニペット」として登録し、**Ctrl + Alt + C**（macOS は **⌃⌥C**）で呼び出して入力できます
  - 一覧で文字を打つと絞り込めます（全角 / 半角、カタカナ / ひらがな、電話番号のハイフンの有無を問わない）
  - Enter で、それまで使っていたアプリにそのまま入力します。⌘ / Ctrl + 1 〜 9 で上から 1 〜 9 番目をすぐ入力できます
  - 「よく使う項目」のボタンから、メールアドレス・電話番号・住所・署名などを 1 クリックで追加できます
- コピーしたテキストを履歴に残し、同じ一覧から選べます
  - パスワード管理ソフトなどが「履歴に残さない」印を付けたコピーは記録しません
  - 件数（既定 200 件）と期間（既定 30 日）の上限を「設定」で変えられます
  - 履歴からスニペットを作れます（⌘ / Ctrl + S）
- macOS で自動で入力するには、アクセシビリティの許可が要ります。許可しないあいだは、選ぶとコピーされるので ⌘V で貼り付けます
- 呼び出すキーは「設定」で 4 つから選べます
- ログイン時に起動、アプリ内アップデートに対応しています
