# ADR-0001：データは JSON、トレイとテーマは Shelf に合わせる

- 状態：採用
- 日付：2026-10-13
- 対象の Standard：Architecture §6（SQLite とロックファイル）、Optional「トレイ常駐」（左クリックで表示の切り替え、右クリックでメニュー）、UI §1（ダークを既定、ライトテーマは作らない）

## 背景

- Clip が持つのは、スニペット（数十件）、コピーの履歴（上限 500 件、1 件 10 万バイトまで）、設定だけ。検索は画面側で全件を見て行う
- Clip は Shelf に続く 2 つ目のトレイ常駐ツール。Shelf の ADR-0001 に「トレイ常駐のツールが 2 つ目にできたら、Standard 側をどちらに寄せるかを決め直す」とある

## 決定

- データは `app_data_dir()` の JSON 3 ファイル（`snippets.json`・`history.json`・`settings.json`）。書くときは一時ファイルに書いてから置き換える。SQLite とロックファイルは使わない（二重起動は single-instance で防ぐ）
- トレイアイコンは **どのクリックでもメニューを出す**。ポップアップはショートカットと、メニューの先頭の「Clip を開く」で出す
- テーマは **OS の設定に合わせて** ライト / ダークを切り替える（`prefers-color-scheme`）。ポップアップはどのアプリの上にも出るため

## 影響

- 履歴が増えるたびに `history.json` を丸ごと書き直す。上限が 500 件なので問題ない大きさだが、画像の履歴を足すなど大きく変えるときは SQLite を考え直す
- トレイの操作とテーマは、トレイ常駐の 2 ツール（Shelf、Clip）でそろった。Standard 側を「トレイ常駐はどのクリックでもメニュー、テーマは OS に合わせる」に寄せるかは、desktop-platform で人が決める
