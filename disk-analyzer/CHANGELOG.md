# Changelog

## 0.2.0

グラフに、読みやすい円グラフと棒グラフを足した。

### 変更点

- グラフに **円グラフ**（⌘4）と **棒グラフ**（⌘5）を足した。いまのフォルダの直下だけを、名前・大きさ・割合つきで出す。サンバースト・ツリーマップ・アイシクルはそのまま
- 最初に出るグラフを棒グラフにした（前にグラフを選んでいた場合は、そのグラフのまま）
- サンバーストのアイコンを円グラフと見分けられるものに替えた

### ダウンロード

- Windows：`Disk_Analyzer_0.2.0_x64-setup.exe`
- macOS（Apple Silicon）：`Disk_Analyzer_0.2.0_aarch64.dmg`

### 注意

- 0.1.0 を入れている場合は、アプリ内アップデートで更新できます（起動して数秒後にダイアログが出ます）
- 初めて入れる場合、Apple や Microsoft の署名をしていないので、初回だけ警告が出ます。
  - Windows：`-setup.exe` を実行 → SmartScreen が出たら「詳細情報」→「実行」
  - macOS：`.dmg` を開いて「アプリケーション」へコピー → 起動すると「開発元を検証できない」と出るので「完了」→ **システム設定 › プライバシーとセキュリティ** の下にある「このまま開く」。ターミナルで `xattr -dr com.apple.quarantine "/Applications/Disk Analyzer.app"` でもよい

## 0.1.0

最初の版（試用版）。ドライブやフォルダの中で、何が容量を使っているかをグラフと一覧で見る。

### 変更点

- スタート画面：ドライブ（ローカル、USB、ネットワークドライブ）とホームフォルダを、使用量と空き容量つきで一覧。フォルダを選ぶ（⌘O）、Finder / エクスプローラーからのドロップ
- スキャン：サブフォルダを並列に読む。見つけた容量・ファイル数・フォルダ数・いま読んでいるフォルダを表示、中止できる。リンクはたどらない、クラウドのみのファイルは 0 として数える、読めないフォルダは飛ばして数を知らせる
- グラフ：サンバースト、ツリーマップ、アイシクルを切り替え（⌘1〜⌘3）。小さい項目は「小さな項目 N 個」にまとめる。重ねるとツールチップ、押すとフォルダの中へ
- 一覧：いまのフォルダの中身を大きい順に、グラフと同じ色で。↑ ↓、Enter、パンくず、上のフォルダへ（⌘↑）
- 右クリック、⌘⇧R、⌘⇧C：エクスプローラー / Finder で表示、パスをコピー。アプリ自体はファイルを変えない
- ウィンドウ、メニューバー、設定（アップデートの自動確認）、ショートカット一覧、ログ、アプリ内アップデート

### ダウンロード

- Windows：`Disk_Analyzer_0.1.0_x64-setup.exe`
- macOS（Apple Silicon）：`Disk_Analyzer_0.1.0_aarch64.dmg`

### 注意

- Apple や Microsoft の署名をしていないので、初回だけ警告が出ます。
  - Windows：`-setup.exe` を実行 → SmartScreen が出たら「詳細情報」→「実行」
  - macOS：`.dmg` を開いて「アプリケーション」へコピー → 起動すると「開発元を検証できない」と出るので「完了」→ **システム設定 › プライバシーとセキュリティ** の下にある「このまま開く」。ターミナルで `xattr -dr com.apple.quarantine "/Applications/Disk Analyzer.app"` でもよい
- macOS で起動ディスク全体を数えるには、**フルディスクアクセス** の許可が要ります（README「インストール」）
