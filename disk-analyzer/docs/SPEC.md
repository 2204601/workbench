# 機能仕様

Disk Analyzer は、ドライブやフォルダの中で何が容量を使っているかを、グラフと一覧で見るアプリ。macOS の DaisyDisk に近い使い方を、Windows でも同じようにできるようにする。

## 1. 方針

- **見るだけ**。アプリはファイルを消さない・動かさない・名前を変えない。片付けは「エクスプローラーで表示」（macOS は「Finder で表示」）から、OS の側で行う
  - 共有フォルダで、ほかの人のファイルを誤って消す事故を起こさないため
  - 削除やごみ箱への移動を足すかどうかは、人が決める（[CLAUDE.md](../CLAUDE.md)「変えないもの」）
- 読むのは名前と大きさだけ。ファイルの中身は開かない
- スキャンした結果はアプリを閉じるまでメモリにだけ持つ。ファイルには残さない

## 2. スタート画面

- ドライブを一覧にする。名前、パス、使用量の棒、空き容量と全体
  - Windows：ドライブ文字のあるもの（ローカル、USB などの外付け、割り当て済みのネットワークドライブ）。CD / DVD は出さない
  - macOS：起動ディスク（中身は `/System/Volumes/Data`）と `/Volumes` にあるもの
- 最後にホームフォルダ
- 「フォルダを選ぶ」（⌘O）と、Finder / エクスプローラーからのドロップで、任意のフォルダ（`\\server\共有\…` も）を選べる
- 項目を押すとすぐにスキャンを始める

## 3. スキャン

- 選んだフォルダの下を全部読む。サブフォルダは並列に読む（ネットワーク越しに効く）
- 進み具合を中央に出す：見つけた容量、ファイル数、フォルダ数、いま読んでいるフォルダ、経過時間。「中止」で止められる
  - 中止したら、前の結果があればそこに戻る。部分的な結果は出さない
- **数え方**
  - リンクはたどらない（シンボリックリンク、Windows のジャンクション）。同じものを 2 回数えない、ループしない
  - macOS / Linux では、フォルダの中にマウントされた別のボリュームには入らない
  - ファイルの大きさはディスク上で使っている分。クラウドにだけあるファイル（OneDrive の「オンラインのみ」、iCloud に退避したもの）は 0 として数え、Windows ではその数をステータスバーに出す
  - macOS / Linux では、ハードリンクが複数あるファイルは 1 回だけ数える
  - 大きさの単位は 1024 進（エクスプローラーと同じく「GB」と書く）
- 読めないフォルダ（アクセスの許可が無いなど）は飛ばして続ける。数はステータスバーとトーストで知らせ、パスはログに残す（最初の 20 件）。一覧ではその行に印を付ける
- 終わったときにアプリが後ろにあり、10 秒以上かかっていたら、OS の通知でも知らせる
- 同時に動くスキャンは 1 つ

## 4. グラフに渡すもの

ツリーは Rust 側だけが持ち、画面は必要な分だけを受け取る。

- `view_tree`：いまのフォルダから決めた深さまで。各フォルダで、いまのフォルダの大きさに対して一定の割合より小さい項目は、1 つの灰色の「小さな項目 N 個」にまとめる。数百万ファイルでも数千の図形に収まる
- `folder_info`：いまのフォルダのパス、合計、パンくず、直下の項目（大きい順に 500 件まで。残りは件数と合計だけ）

## 5. グラフ

表示は 3 種類から選べる（⌘1 ⌘2 ⌘3、ツールバーの切り替え）。選んだものは次に起動したときも使う。

| | 形 | 深さ | まとめる割合 |
|---|---|---|---|
| サンバースト | DaisyDisk と同じ。中心から外へ 1 段ずつ深くなる。角度が大きさ | 5 段 | 0.4% |
| ツリーマップ | WizTree と同じ。入れ子の四角。面積が大きさ | 3 段 | 0.05% |
| アイシクル | 左から右へ 1 段ずつ。高さが大きさ | 4 段 | 0.2% |

共通の動き：

- **色**：いまのフォルダの直下の項目に、大きい順に 8 色を割り当てる。その下の項目は同じ色で、深いほど薄い。9 番目以降と「小さな項目」は灰色。一覧の色見本と同じ
- フォルダを押すとその中へ入る。ファイルを押すと選ぶ（点線の枠）
- 項目に重ねると白い枠と、名前・場所・大きさ・いまのフォルダに対する割合・ファイル数のツールチップ。一覧で重ねた行も、グラフ側に枠が出る
- サンバーストの中心は、いまのフォルダ（重ねている間はその項目）の名前と大きさ。押すと上のフォルダへ。アイシクルは左端の列を押すと上へ
- 右クリック：開く（フォルダ）、エクスプローラーで表示、パスをコピー
- 文字は入る大きさの区画にだけ出す（ツリーマップは大きい箱と直下のフォルダの見出し、アイシクルはほぼ全部、サンバーストは中心だけ）

## 6. 一覧とステータスバー

- 右の一覧：いまのフォルダの直下を大きい順に。色見本、フォルダ / ファイル、名前、大きさ、いちばん大きい項目に対する棒、いまのフォルダに対する割合
  - フォルダの行を押すと中へ。ファイルの行を押すと選ぶ。↑ ↓ で選ぶ行を動かし、Enter で選んだフォルダに入る
- ツールバー：スタート画面へ、上のフォルダへ、パンくず（押すとそこへ戻る）、グラフの切り替え、もう一度スキャン、フォルダを選ぶ
- ステータスバー：いまのフォルダの大きさ・ファイル数・フォルダ数・パス、読めないフォルダの数、クラウドのみのファイル数、ネットワーク上かどうか、スキャンにかかった時間、ドライブの空き容量
