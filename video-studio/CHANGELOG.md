# Changelog

## 0.1.0

最初の版（試用版）。動画を切って並べ、文字やスタンプ、切り替えを入れて MP4 に書き出す。

### 変更点

- 素材：動画・写真をドロップか ⌘I で追加すると、タイムラインの最後に並ぶ。サムネイルと波形。ウィンドウで再生できない動画（iPhone の HEVC、.mts など）はプレビュー用のコピーを作る
- キリはり：再生位置で分割（S）、削除（Delete）、端のドラッグで切り詰め、ドラッグで並べ替え、コピー・ペースト・複製、取り消し・やり直し
- 文字：プリセット 7 種、フォント・大きさ・色・ふち・背景の帯・位置・回転。出し方・消し方（フェード、ポップ、下から、左から）
- スタンプ：絵文字 50 種、図形 8 種（色を選べる）
- 切り替え：クロスフェード、黒・白を挟む、ワイプ、スライド、円で開く・閉じる（長さも変えられる）
- 書き出し：MP4（H.264 / AAC）、1080p・720p、画質 3 段階、24 / 30 / 60 fps。進み具合と中止
- 画面の形（16:9 / 9:16 / 1:1）、クリップの音量、プロジェクトの保存（.cutter）
- ウィンドウ、メニューバー、設定（アップデートの自動確認）、ショートカット一覧、ログ、アプリ内アップデート

### ダウンロード

- Windows：`Video_Studio_0.1.0_x64-setup.exe`
- macOS（Apple Silicon）：`Video_Studio_0.1.0_aarch64.dmg`

### 注意

- Apple や Microsoft の署名をしていないので、初回だけ警告が出ます。
  - Windows：`-setup.exe` を実行 → SmartScreen が出たら「詳細情報」→「実行」
  - macOS：`.dmg` を開いて「アプリケーション」へコピー → 起動すると「開発元を検証できない」と出るので「完了」→ **システム設定 › プライバシーとセキュリティ** の下にある「このまま開く」。ターミナルで `xattr -dr com.apple.quarantine "/Applications/Video Studio.app"` でもよい
- 書き出しには同梱の ffmpeg（GPL）を使います（README「ffmpeg について」）
