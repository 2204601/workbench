# 機能仕様

Video Studio は、動画や写真を切って並べ、文字やスタンプを重ね、つなぎ目に切り替えを入れて MP4 に書き出すアプリ。iMovie や CapCut の基本の操作を、社内の Windows でも同じようにできるようにする。

## 1. 方針

- **かんたんな編集だけ**。キリはり、文字、スタンプ、切り替え、音量。複数の映像トラック、色の調整、速さの変更、音楽トラック（BGM）は今は入れない
- 素材のファイルは **読むだけ**。編集はプロジェクト（`.vstudio`）にだけ持ち、書き出すときに元のファイルから作る
- プレビューと書き出しは同じ見た目にする。文字とスタンプは同じ絵（canvas）を使い、切り替えとアニメーションは ffmpeg と同じ計算で描く
- ネットワークに出ない（updater を除く）。ffmpeg も同梱

## 2. 画面

- 上：新規・開く・保存、取り消す・やり直す、プロジェクト名（未保存は ●）、画面の形（16:9 / 9:16 / 1:1）、書き出す
- 左：素材 / テキスト / スタンプ / 切り替え のタブ
- 中央：プレビューと再生ボタン、時間
- 右：選んだもの（クリップ、つなぎ目、文字、スタンプ）の設定。何も選んでいないときはプロジェクトの情報と使い方
- 下：タイムライン。上から目盛り、映像（クリップ）、文字とスタンプ（重なると段が増える）。高さは上の縁のドラッグで変えられる

## 3. 素材

- 追加：ドロップか「動画・写真を追加」（⌘I）。追加した順に **タイムラインの最後に並ぶ**。`.vstudio` のドロップはプロジェクトとして開く
- 読めるもの：ffmpeg が読める動画と写真（mp4、mov、mkv、webm、avi、mts、jpg、png、webp、gif、heic など）。音声だけのファイルはまだ使えない
- 最初の素材の向きで画面の形を決める（横長 → 16:9、縦長 → 9:16、正方形 → 1:1）
- 追加すると裏で、サムネイル（キーフレームから最大 60 枚）と音の波形を作る。ウィンドウがそのまま再生できない動画（§8）は、プレビュー用のコピー（720p、H.264、0.5 秒ごとのキーフレーム）も作る。進み具合は素材の一覧に出す
- 素材の一覧から、ダブルクリック・＋・ドラッグでタイムラインに入れられる（＋とダブルクリックは再生位置のクリップの境目に、ドラッグは落とした位置に）
- 使っていない素材は一覧から外せる

## 4. タイムライン

- 映像は **詰めて並ぶ**（すき間はできない）。写真は 3 秒で入る
- クリップを押すと選び、再生位置も押した場所へ動く。ドラッグで並べ替え（入る位置に黄色の線）。端のドラッグで切り詰め・伸ばし（動画は元のファイルの長さまで、写真は自由。プレビューは端のコマを出す）
- 再生位置で分割（S、⌘B）。端から 0.1 秒以内では分割しない。分割したあとは後ろ側を選ぶ
- 削除（Delete）すると後ろが詰まる。コピー・カット・ペースト（クリップは選んだクリップの後ろか再生位置に、文字・スタンプは再生位置に）、複製（⌘D）
- つなぎ目の ◇：押すと選んで、左のタブが「切り替え」になる。切り替えがあると色が付き、重なる部分に斜線
- 文字・スタンプは時間の位置にだけ並び、押すと選んで再生位置もそこへ。ドラッグで動かす、端で長さを変える。ほかの端や再生位置に吸い付く（8 px）
- 目盛りを押す・ドラッグすると再生位置が動く。空いたところを押すと選択を解除してそこへ
- 拡大縮小：⌘= / ⌘- / ⌘0（全体）、⌘ + ホイール（ポインタの位置を中心に）、つまみ
- 再生中は再生位置が見えるように横に送る
- 時間はすべて **フレーム単位**（プロジェクトの fps）で丸める。書き出し（`render.rs`）と同じ丸め方

## 5. 切り替え

- つなぎ目ごとに 1 つ。前のクリップの終わりと次のクリップの初めを重ねるので、その長さだけ全体が短くなる
- 種類：クロスフェード、黒を挟む、白を挟む、ワイプ（左・右・上・下へ）、スライド（左・右・上・下へ）、円で開く、円で閉じる（ffmpeg `xfade` の fade、fadeblack、fadewhite、wipeleft…、circleopen、circleclose）
- 長さ：既定 0.5 秒、0.1〜3 秒。前のクリップの残りと次のクリップのどちらより長くはならない（短いときは右の欄に実際の長さを出す）。同時に映るのは 2 つまで
- 「すべてのつなぎ目に」で一度に入れられる
- 音は同じ長さでクロスフェード

## 6. 文字とスタンプ

- 再生位置から 3 秒で入る（最後の 3 秒より後ろでは、最後の 3 秒に）。入れたら選んだ状態になり、文字は入力欄にすぐ打てる
- 文字：改行あり。フォント（ゴシック・明朝・やわらか。OS のフォントを使う）、太字、大きさ（1080 の画面で 24〜300 px。画面の大きさに合わせて変わる）、色、ふち、背景の帯（角丸）
- スタンプ：絵文字（OS の絵文字のフォント）と図形（色を選べる）
- 位置（プレビューの上でドラッグ。真ん中の線に吸い付き、線が出る。上・真ん中・下のボタン）、大きさ（右下の角、20〜400%）、回転（上の丸。Shift で 15° ずつ、0° と 90° ごとに吸い付く）
- 出るとき・消えるとき：なし、フェード、ポップ、下から / 上へ、左から / 右へ。長さは 0.4 秒（表示が 0.8 秒より短いときはその半分）
- 選んでいる文字・スタンプは、止まっているあいだアニメーションなしで全部見せる（入れたばかりで見えない、を避ける）
- 後から入れたものほど上に重なる

## 7. 書き出し

- ⌘E のダイアログで、大きさ（1080p / 720p。プロジェクトの短い辺に合わせる）、画質（高画質 CRF 18 / 標準 22 / 軽量 28）、フレームレート（24 / 30 / 60）を選び、保存先を選ぶ
- MP4（H.264 yuv420p、AAC 48 kHz ステレオ、faststart）
- 進み具合（%、書いた時間、残りの目安）と中止。終わったらトーストに「Finder / エクスプローラーで表示」。10 秒以上かかってアプリが後ろにあれば OS の通知も
- 途中のファイルは `<名前>.part.mp4` に書き、終わったら名前を変える。失敗・中止したら消す
- 写真はページで画面の大きさに合わせて描いた PNG を渡す（EXIF の向きと HEIC を、プレビューと同じに読むため）

## 8. プレビューで再生できるもの

- Windows（WebView2）：MP4 / MOV の H.264（8bit）、MP4 / WebM の VP8・VP9・AV1
- macOS（WKWebView）：MP4 / MOV の H.264（8bit）と HEVC
- それ以外はプレビュー用のコピーを作る。上に当てはまっても再生に失敗したら、そのときにコピーを作る
- プレビューの音量は 100% まで

## 9. プロジェクト

- `.vstudio`（JSON）。素材はフルパスで持つ。開いたとき、見つからない素材は一覧とプレビューに「見つかりません」と出す
- 未保存のまま新規・開く・ウィンドウを閉じると確かめる
- 取り消しは 100 回まで。ドラッグやつまみは、離したときに 1 回分

## 10. キーボード

README の「キーボード」の表のとおり。コマンド表（`src/lib/commands.ts`）から、メニューとショートカット一覧（?）を作る。コピー・カット・ペーストは、文字の入力欄では欄のもの、それ以外ではクリップと文字・スタンプのもの。
