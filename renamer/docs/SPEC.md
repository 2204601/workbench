# 機能仕様（v0.1.0）

ユーザーから見た振る舞いを決める。内部の作りは [ARCHITECTURE.md](ARCHITECTURE.md)、事故を防ぐ仕組みは [SAFETY.md](SAFETY.md)。
「案」と書いたところは計画段階の提案で、実装前に確定させる。

## 1. 目的

フォルダの中のファイル名を、ルールに沿って一括で変える。社内の共有フォルダ（NAS、`\\server\share`、OneDrive）でも安全に使えることを優先する。

- **変更前に必ず結果を見せる**（プレビュー）。
- **問題のある名前は実行させない**（衝突、Windows で使えない文字）。
- **直前の 1 回は元に戻せる**。アプリが途中で落ちても戻せる。

## 2. 利用者とモード

| モード | 想定する人 | 違い |
|---|---|---|
| 簡単 | 正規表現を知らない一般ユーザー | 各ルールをフォームで操作する。記号を覚えなくてよい |
| 詳細 | IT 担当者 | 正規表現、テンプレートの書式を直接書ける |

- 切り替えはルールパネルの上のトグル。最後に使ったモードを `localStorage` に覚える。
- 詳細モードの入力（正規表現のチェック、テンプレート、日付の書式）は簡単モードに戻しても残るが、簡単モードの間は使わない。

## 3. 画面

ウィンドウ 1 枚。

```text
┌───────────────────────────────────────────────────────────────┐
│ [フォルダを開く] [ファイルを追加]  絞り込み: [拡張子▼] [名前に含む…] │ ツールバー
├──────────────────┬────────────────────────────────────────────┤
│ 簡単 | 詳細       │ ☑ 元の名前          → 新しい名前          状態 │
│                  │ ☑ IMG_0001.JPG      → 現場_001.JPG       ✓    │
│ ○ 置換           │ ☑ IMG_0002.JPG      → 現場_002.JPG       ✓    │
│ ○ 連番           │ ☑ 見積書.xlsx        → 見積書.xlsx         ―    │
│ ○ 日付           │ ☑ 報告:最終.docx     → 報告:最終.docx      ⚠ 使えない文字 │
│ ○ 整形           │   …（仮想スクロール）                          │
│                  │                                            │
│ （ルールの設定）    │ 表示: [すべて | 変わるもの | 問題のあるもの]      │
├──────────────────┴────────────────────────────────────────────┤
│ 1,204 件中 1,180 件を変更 / 問題 2 件 / \\nas01\共有 (ネットワーク)  [実行] │ ステータスバー
└───────────────────────────────────────────────────────────────┘
```

- 何も読み込んでいないときは一覧の場所に「フォルダかファイルをここへドロップ」の案内を出す（UI Standard §9 の Welcome の代わり）。
- 行のチェックを外すと、その行は対象から外れる（問題の解消手段の 1 つ）。

## 4. 読み込み

| 方法 | 振る舞い |
|---|---|
| フォルダを開く（⌘O）／フォルダをドロップ | そのフォルダの直下のファイルで **新しい一覧** にする。**サブフォルダは含めない**。フォルダとファイルを一緒にドロップしたときも新しい一覧 |
| ファイルを追加（⌘⇧O）／ファイルだけをドロップ | 今の一覧に足す。別のフォルダのファイルが混ざってもよい。1 つずつ選んだファイルは隠しファイルでも足す |

- **フォルダ自体の名前は変えない**。一覧にも出さない。
- 既定で除外するもの：隠しファイル（先頭が `.` のものはどの OS でも隠しファイルとみなす。Mac が共有フォルダに残す `._名前` を含む）、システムファイル、`desktop.ini`、`Thumbs.db`、`.DS_Store`、`~$` で始まる Office の一時ファイル。設定で表示できるようにする（案）。
- 絞り込み：拡張子（複数選択）、名前に含む文字列。絞り込みで外れたファイルは対象外だが、**衝突の検査には使う**（同じフォルダに実在するため）。
- 読み込みはバックグラウンドで行い、1 秒を超えたら進捗と「中止」を出す。

## 5. ルール

1 回の実行に使うルールは 1 つ。ルールを変えるとプレビューがすぐ更新される（入力から 150 ms 程度待ってから計算する）。

### 5.1 拡張子の扱い（全ルール共通）

- 既定では、ルールは **拡張子を除いた部分** にだけかかる。
- 「拡張子も対象にする」にチェックを入れると、ファイル名全体にかかる。
- 拡張子は最後の `.` から後ろとする。`.gitignore` のように先頭が `.` だけの名前は、全体を名前として扱う。

### 5.2 置換

| | 簡単 | 詳細 |
|---|---|---|
| 検索 | 文字列 | 正規表現（Rust `regex` の書式。先読み・後読みは使えない） |
| 置換後 | 文字列 | `$1`、`${name}` でグループを参照できる |
| オプション | 大文字小文字を区別する、最初の 1 つだけ | 同左 |

簡単モードには、よく使う操作を別のフォームとして置く。

- 先頭に追加／末尾に追加
- 指定した文字を削除
- 先頭から N 文字を削除／末尾から N 文字を削除

正規表現が書式として正しくないときは、入力欄の下に理由を出し、一覧は前の結果のままにする。

### 5.3 連番・テンプレート

- 簡単：「先頭に番号」「末尾に番号」「番号だけにする」から選び、開始番号、桁数（ゼロ埋め）、区切り文字（`_`、`-`、スペース、なし）を決める。
- 詳細：テンプレートを書く。

| トークン | 中身 |
|---|---|
| `{name}` | 元の名前（拡張子を除く） |
| `{n}` / `{n:3}` | 連番 / 3 桁のゼロ埋め |
| `{parent}` | 親フォルダの名前 |
| `{mdate:yyyyMMdd}` | 更新日時（書式は §5.4） |
| `{cdate:yyyyMMdd}` | 作成日時 |

例：`現場A_{mdate:yyyyMMdd}_{n:3}` → `現場A_20261011_001.jpg`

**番号を振る順番**：一覧の並び順とする。並び替えは次から選ぶ（案）。手で並べ替える機能は第 2 版。

- 名前（自然順。`2` が `10` より前）※既定
- 更新日時
- 作成日時
- それぞれ昇順・降順

### 5.4 日付

- 使う日時：更新日時（既定）／作成日時。
- 付ける位置：先頭／末尾／名前を日付で置き換える（このとき同じ日時のものは衝突として表示される）。
- 書式：`yyyyMMdd`（既定）、`yyyy-MM-dd`、`yyyyMMdd_HHmmss`、`yyMMdd`。詳細モードでは書式を直接書ける。
- 時刻は PC のローカル時刻。
- 作成日時は、コピーしたときや NAS では「コピーした日時」になることがある。日時を選ぶ欄の下に一言添える。

EXIF の撮影日時、文書のプロパティは第 2 版以降。

### 5.5 文字種の整形

チェックボックスで複数を選べる（1 つのルールとして同時にかかる）。

| 項目 | 内容 |
|---|---|
| 全角英数字・記号 → 半角 | `ＡＢＣ１２３` → `ABC123` |
| 半角カナ → 全角 | `ｶﾞｲﾄﾞ` → `ガイド` |
| 大文字 / 小文字 / 先頭だけ大文字 | 英字だけ |
| 空白をそろえる | 全角スペース → 半角、連続した空白を 1 つ、前後の空白を削除 |
| 空白を置き換える | 空白を `_` または `-` に |
| Windows で使えない文字を置き換える | `\ / : * ? " < > \|` を全角に、または `_` に |
| 日本語の表記をそろえる（NFC） | Mac で付けた「ガ」などの分かれた文字を 1 文字にまとめる。**既定でオン** |

## 6. プレビューと検査

各行の状態：

| 状態 | 表示 | 実行できるか |
|---|---|---|
| 変わる | 新しい名前を強調 | ○ |
| 変わらない | 灰色の「―」 | 対象外として扱う |
| 問題あり | 赤い ⚠ と理由 | × 解消するまで実行ボタンを押せない |
| 注意 | 黄色の ! と理由 | ○（確認ダイアログで件数を出す） |

**問題あり**（実行させない）：

- 同じフォルダの既存ファイルと同じ名前になる（大文字小文字と NFC の違いは同じとみなす）
- 一覧の中のほかのファイルの新しい名前と同じになる
- Windows で使えない文字（`\ / : * ? " < > |`、制御文字）を含む
- Windows の予約名（`CON`、`PRN`、`AUX`、`NUL`、`COM1`〜`COM9`、`LPT1`〜`LPT9`。拡張子付きも）
- 末尾がピリオドか空白
- 名前が空になる
- 名前が 255 文字（UTF-16）を超える

**注意**（実行はできる）：

- フルパスが 260 文字を超える（エクスプローラーやほかのアプリで開けなくなることがある）
- 拡張子が変わる

問題の解消方法：ルールを直す／その行のチェックを外す／「問題のある行をすべて外す」ボタン。

## 7. 実行

1. 実行ボタン（⌘Enter）を押す
2. 確認ダイアログ：「1,180 件の名前を変更します」。ネットワーク上のフォルダなら「ほかの人のショートカットや Excel のリンクが切れることがあります」を添える。ボタンは「変更する」「キャンセル」
3. 進捗バーと「中止」。ウィンドウは固まらない。10 秒以上かかり、終わったときにウィンドウが前に無ければ OS の通知
4. 終わったら一覧を新しい名前にし、トースト「1,180 件の名前を変更しました」と「元に戻す」。ルールは休止し（同じルールが新しい名前にもう一度かからないように）、ルールを変えるとまたプレビューする

**途中で失敗したとき**（ロック中、権限なし、接続が切れた）は、その場で止めてダイアログを出す。

> 32 件目「見積書.xlsx」を変更できませんでした。ほかの人が開いている可能性があります。
> 31 件は変更済みです。
> [変更した 31 件を元に戻す] [失敗したものを飛ばして続ける] [ここで終える]

「中止」を押したときも同じ選択肢を出す（「続ける」を除く）。

## 8. 元に戻す

- 対象は **直前の 1 回** だけ。次に実行すると前の分は戻せなくなる。
- トーストの「元に戻す」、メニュー、⌘Z から。
- 戻す前に 1 件ずつ、今の名前のままかを確かめる。ほかの人が変えたものは戻さず、最後に一覧で知らせる。
- アプリを閉じても、次に起動したときに戻せる。実行中にアプリが落ちた場合は、起動時に「前回の変更が途中で終わっています。元に戻しますか」と聞く。

## 9. キーボード

macOS 表記。Windows は ⌘ → Ctrl、⌥ → Alt。

| キー | 操作 |
|---|---|
| ⌘O | フォルダを開く |
| ⌘⇧O | ファイルを追加 |
| ⌘F | 名前の絞り込みへ |
| ⌘1〜⌘4 | ルールを切り替える（置換、連番、日付、整形） |
| ⌘Enter | 実行 |
| ⌘Z | 元に戻す |
| Space | 選択した行のチェックを切り替える |
| ↑ ↓、⇧、⌘A | 行の選択 |
| ⌘, | 設定 |
| ? | ショートカット一覧 |
