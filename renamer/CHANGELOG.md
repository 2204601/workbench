# Changelog

## 0.1.1

### 変更点

- macOS で、ウィンドウ左上の 3 つのボタン（閉じる・最小化・拡大）が、ツールバーのボタンより少し上にずれていたのを直した。ツールバーの高さの真ん中にそろう

### ダウンロード

- Windows：`Renamer_0.1.1_x64-setup.exe`
- macOS（Apple Silicon）：`Renamer_0.1.1_aarch64.dmg`

### 注意

- 0.1.0 を使っている場合は、アプリ内アップデートで入れ替わります（起動後に自動で確認します。すぐ確かめるならメニューの「アップデートを確認…」）
- 初めて入れる場合は、Apple や Microsoft の署名をしていないので、初回だけ警告が出ます。
  - Windows：`-setup.exe` を実行 → SmartScreen が出たら「詳細情報」→「実行」
  - macOS：`.dmg` を開いて「アプリケーション」へコピー → 起動すると「開発元を検証できない」と出るので「完了」→ **システム設定 › プライバシーとセキュリティ** の下にある「このまま開く」。ターミナルで `xattr -dr com.apple.quarantine "/Applications/Renamer.app"` でもよい

## 0.1.0

最初の版（試用版）。フォルダの中のファイル名を、ルールに沿って一括で変える。

### 変更点

- ウィンドウ、メニューバー、設定（アップデートの自動確認）、ショートカット一覧、ログ、アプリ内アップデート
- 読み込み：フォルダを開く（⌘O）、ファイルを追加（⌘⇧O）、Finder / エクスプローラからのドロップ。隠しファイルと `desktop.ini` などは除く。ネットワーク上のフォルダはステータスバーに表示
- 一覧：拡張子と名前で絞り込み、名前（自然順）・更新日時・作成日時・サイズで並べ替え、行ごとに対象から外せる。1 万件でも固まらない
- ルール：置換（文字列・正規表現、先頭／末尾に追加、文字の削除、先頭・末尾から削除）、連番、日付（更新日時・作成日時）、整形（全角半角、半角カナ、大文字小文字、空白、使えない文字、NFC）。簡単モードと詳細モード（正規表現、テンプレート）
- プレビュー：入力に合わせて新しい名前を表示。名前の衝突（ほかのファイル、一覧どうし、大文字小文字や表記の違いも同じとみなす）と Windows で使えない名前は「問題」として表示。拡張子が変わる、パスが長いものは「注意」
- 実行（⌘Enter）：確認のダイアログ（ネットワーク上ならリンク切れの注意）、進捗と中止。名前を変える直前に 1 件ずつ確かめ、上書きしないリネームで変える。入れ替えや大文字小文字だけの変更は一時的な名前を経由する
- 途中で失敗したら止まり、「元に戻す / 飛ばして続ける / ここで終える」を選べる
- 元に戻す（⌘Z）：直前の 1 回。アプリを閉じた後でも、落ちた後でも戻せる。ほかの人が変えたファイルは戻さずに知らせる

### ダウンロード

- Windows：`Renamer_0.1.0_x64-setup.exe`
- macOS（Apple Silicon）：`Renamer_0.1.0_aarch64.dmg`

### 注意

- **試用版です。** 社内の共有フォルダ（NAS）での確認がまだです。最初は大事なフォルダそのものでなく、**コピーしたフォルダ** で試してください。おかしな動きがあれば、**ヘルプ › ログを表示** のログを添えて知らせてください。
- Apple や Microsoft の署名をしていないので、初回だけ警告が出ます。
  - Windows：`-setup.exe` を実行 → SmartScreen が出たら「詳細情報」→「実行」
  - macOS：`.dmg` を開いて「アプリケーション」へコピー → 起動すると「開発元を検証できない」と出るので「完了」→ **システム設定 › プライバシーとセキュリティ** の下にある「このまま開く」。ターミナルで `xattr -dr com.apple.quarantine "/Applications/Renamer.app"` でもよい
- 2 回目以降の版は、アプリ内アップデートで入れ替わります（警告は出ません）。
