# Changelog

リリースは GitHub Actions の shelf ワークフローを `release` にチェックを入れて手動実行するか、`shelf-v<バージョン>` のタグを push すると作成されます。本文はこのファイルの該当バージョンの節から取られます。

## 未リリース

- ドラッグ中に棚が出てくるようになりました
  - ファイルを画面の右端まで持っていくと出てきます（macOS / Windows）
  - macOS では、ファイルをドラッグし始めた時点で出てきます
  - 何も置かずにドラッグを終えると、また隠れます
- 棚が空のあいだはウィンドウを隠すようにしました。最後のアイテムを出すと自動で隠れます

## 0.1.1

配布物を整理したリリースです。アプリの機能は 0.1.0 から変わっていません。

### 変更点

- macOS は Apple Silicon（M1 以降）専用になりました。Intel Mac 向けの版は配布しません
- Windows は `-setup.exe` のみになりました（`.msi` は廃止）

### ダウンロード

| OS | ファイル |
| --- | --- |
| macOS（Apple Silicon） | `.dmg` |
| Windows | `-setup.exe` |

### 注意

- コード署名をしていないため、初回起動時に警告が出ます。
  - macOS: アプリを右クリック →「開く」。「壊れている」と表示される場合は、ターミナルで `xattr -cr /Applications/Shelf.app` を実行してから開いてください
  - Windows: SmartScreen の画面で「詳細情報」→「実行」
- 0.1.0 から入れ替える場合は、そのままインストールして上書きしてください（棚の中身は引き継がれます）

## 0.1.0

最初のリリースです。

### できること

- Finder / エクスプローラからファイル・フォルダを棚にドロップ（場所だけを記録し、コピーは作りません）
- 棚から目的の場所へドラッグで出す。既定は「移動」で、移動したアイテムは棚から自動で消えます
  - ヘッダーで「コピー」に切り替え可能。Alt（macOS は Option）を押しながらだとその回だけ反転
- 複数選択（⌘/Ctrl・Shift）と「まとめてドラッグ」
- ダブルクリックで開く、Finder / エクスプローラで表示、棚から外す
- 元の場所から消えたファイルはグレーで「見つかりません」と表示
- 棚の中身は再起動後も保持
- 画面右端に常に最前面で表示。メニューバー / タスクトレイのアイコンから表示切替・終了（macOS では Dock に出ません）

### ダウンロード

| OS | ファイル |
| --- | --- |
| macOS（Apple Silicon / Intel 共通） | `.dmg` |
| Windows | `-setup.exe`（おすすめ）または `.msi` |

### 注意

- コード署名をしていないため、初回起動時に警告が出ます。
  - macOS: アプリを右クリック →「開く」。「壊れている」と表示される場合は、ターミナルで `xattr -cr /Applications/Shelf.app` を実行してから開いてください
  - Windows: SmartScreen の画面で「詳細情報」→「実行」
- 自動アップデートはありません。新しい版は手動で入れ替えてください。
