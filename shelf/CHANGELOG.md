# Changelog

リリースは GitHub Actions の shelf ワークフローを `release` にチェックを入れて手動実行するか、`shelf-v<バージョン>` のタグを push すると作成されます。本文はこのファイルの該当バージョンの節から取られます。

## 0.1.3

アプリ内アップデートに対応しました。この版を入れておけば、次からは新しい版をダウンロードし直す必要はありません。

### 変更点

- 起動から数秒後に新しいバージョンを確認し、あればダイアログで知らせます。「更新して再起動」で適用されます
- メニューバー / タスクトレイのアイコンの右クリックメニューに「アップデートを確認…」を追加しました
- 会社のネットワークなどでプロキシが必要な場合も、OS のプロキシ設定（PAC を含む）を使って確認します
- macOS 版にアドホック署名をするようにしました。初回起動時に「壊れているため開けません」ではなく「開発元を検証できない」と出るようになり、システム設定から開けます

### ダウンロード

| OS | ファイル |
| --- | --- |
| macOS（Apple Silicon） | `.dmg` |
| Windows | `-setup.exe` |

### 注意

- 署名（Apple Developer ID / Windows コード署名）なしのビルドなので、初回インストール時だけ警告が出ます。
  - macOS: 起動すると「開発元を検証できない」と出るので「完了」→ システム設定 › プライバシーとセキュリティ の下にある「このまま開く」。ターミナルで `xattr -dr com.apple.quarantine /Applications/Shelf.app` を実行しても構いません
  - Windows: SmartScreen の画面で「詳細情報」→「実行」
- 0.1.2 以前から入れ替える場合は、今回だけそのままインストールして上書きしてください（棚の中身は引き継がれます）。次の版からはアプリ内で更新できます

## 0.1.2

ドラッグ中に棚が出てくるようになりました。

### 変更点

- 棚が隠れているとき、ファイルを**画面の右端**まで持っていくと棚が出てきます（macOS / Windows）
  - 右端の中ほどにある細い青い線が目印です。線の上に直接ドロップしても棚に置けます
- macOS では、Finder などでファイルを**ドラッグし始めた時点**で棚が出てきます
- 何も置かずにドラッグを終えると、棚はまた隠れます
- 棚が空のあいだはウィンドウを隠すようにしました。最後のアイテムを出す・棚を空にすると自動で隠れます
  - 起動時は、棚にアイテムがあるときだけ表示されます（初回起動時は表示）

### ダウンロード

| OS | ファイル |
| --- | --- |
| macOS（Apple Silicon） | `.dmg` |
| Windows | `-setup.exe` |

### 注意

- コード署名をしていないため、初回起動時に警告が出ます。
  - macOS: アプリを右クリック →「開く」。「壊れている」と表示される場合は、ターミナルで `xattr -cr /Applications/Shelf.app` を実行してから開いてください
  - Windows: SmartScreen の画面で「詳細情報」→「実行」
- 以前の版から入れ替える場合は、そのままインストールして上書きしてください（棚の中身は引き継がれます）

## 0.1.0

最初のリリースです。

### できること

- Finder / エクスプローラからファイル・フォルダを棚にドロップ（場所だけを記録し、コピーは作りません）
- 棚から目的の場所へドラッグで出す。既定は「移動」で、移動したアイテムは棚から自動で消えます
  - ヘッダーで「コピー」に切り替え可能。Alt（macOS は Option）を押しながらだとその回だけ反転
- 複数選択（⌘/Ctrl・Shift）と「まとめてドラッグ」
- ダブルクリックで開く、Finder / エクスプローラで表示、棚から外す
- 元の場所から消えたファイルはグレーで「見つかりません」と表示
- 棚の中身は再起動後も保持
- 画面右端に常に最前面で表示。メニューバー / タスクトレイのアイコンから表示切替・終了（macOS では Dock に出ません）

### ダウンロード

| OS | ファイル |
| --- | --- |
| macOS（Apple Silicon / Intel 共通） | `.dmg` |
| Windows | `-setup.exe`（おすすめ）または `.msi` |

### 注意

- コード署名をしていないため、初回起動時に警告が出ます。
  - macOS: アプリを右クリック →「開く」。「壊れている」と表示される場合は、ターミナルで `xattr -cr /Applications/Shelf.app` を実行してから開いてください
  - Windows: SmartScreen の画面で「詳細情報」→「実行」
- 自動アップデートはありません。新しい版は手動で入れ替えてください。
