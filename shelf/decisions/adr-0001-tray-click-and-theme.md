# ADR-0001：トレイのクリックとテーマ

- 状態：採用
- 日付：2026-10-12
- 対象の Standard：Optional「トレイ常駐」（左クリックで表示の切り替え、右クリックでメニュー）、UI §1（ダークを既定、ライトテーマは作らない）

## 背景

- 0.1.2 までは、トレイアイコンの左クリックで棚の表示を切り替えていた。棚は空のあいだ隠れていて、ドラッグを始めれば出てくるため、クリックで出す必要はほとんど無い。一方で「アップデートを確認…」「ログイン時に起動」などの項目は、右クリックを知らないと見つからなかった
- 棚は Finder / エクスプローラの横に常に重ねて置く小さなウィンドウで、まわりはライトのことも多い

## 決定

- トレイアイコンは **どのクリックでもメニューを出す**（0.1.3 から）。表示の切り替えはメニューの先頭の「表示 / 非表示」と、ショートカット Ctrl + Alt + S（⌃⌥S）で行う
- テーマは **OS の設定に合わせて** ライト / ダークを切り替える（`prefers-color-scheme`）。色は `src/styles.css` の `:root` の変数にまとめてある

## 影響

- 1 クリックで棚を出す操作は無くなった。ショートカットとドラッグで代わりにする
- ほかのツールとトレイの操作が違う。トレイ常駐のツールが 2 つ目にできたら、Standard 側をどちらに寄せるかを決め直す
