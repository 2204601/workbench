# Changelog

## 0.1.0

最初の版（試用版）。PDF を見る・ページを整理する・書き込む・フォームに入力する。

### 変更点

- 開く：⌘O、ドロップ、「このアプリで開く」。タブで複数。最近使ったファイル
- 見る：幅に合わせる・ページ全体・拡大縮小、サムネイル、コメント一覧、しおり、文字の選択とコピー、リンク
- 検索：大文字小文字・全角半角・空白の違いを無視して探す
- ページの整理：並べ替え、回転、削除、白紙の挿入、別の PDF の挿入（結合）、書き出し（抽出）、分割
- 注釈：マーカー、下線、取り消し線、テキストボックス、付箋、ペン、四角形、楕円、直線、矢印、画像・印鑑（ライブラリ付き）。移動、大きさ、色、太さ、不透明度、コメント、複製
- フォーム入力：テキスト、チェック、ラジオ、選択
- 保存：別名の提案、上書き前のバックアップ。日本語はパソコンのフォントを埋め込むので、どのビューアでも同じに見える
- 元に戻す・やり直す、メニューバー、設定（作成者名、アップデートの自動確認）、ショートカット一覧、ログ、アプリ内アップデート

### ダウンロード

- Windows：`PDF_Editor_0.1.0_x64-setup.exe`
- macOS（Apple Silicon）：`PDF_Editor_0.1.0_aarch64.dmg`

### 注意

- Apple や Microsoft の署名をしていないので、初回だけ警告が出ます。
  - Windows：`-setup.exe` を実行 → SmartScreen が出たら「詳細情報」→「実行」
  - macOS：`.dmg` を開いて「アプリケーション」へコピー → 起動すると「開発元を検証できない」と出るので「完了」→ **システム設定 › プライバシーとセキュリティ** の下にある「このまま開く」。ターミナルで `xattr -dr com.apple.quarantine "/Applications/PDF Editor.app"` でもよい
- もとの文字の書き換え、印刷、保護された PDF の編集はまだできません（README「できないこと」）
