# ADR-0001：テーマは OS に合わせる

- 状態：採用
- 日付：2026-10-13
- 対象の Standard：UI §1（ダークを既定、ライトテーマは作らない）

## 背景

- Meter のポップアップは、タスクバー / メニューバーのアイコンのそばに、どのアプリの上にも開く。OS 自身のフライアウト（音量、ネットワーク、カレンダー）は OS のライト / ダークに合わせて出る
- トレイ常駐の Shelf と Clip は、同じ理由でテーマを OS に合わせている（それぞれの ADR-0001）。Clip の ADR は、Standard 側を寄せるかを desktop-platform で人が決めるとしている

## 決定

- テーマは **OS の設定に合わせて** ライト / ダークを切り替える（`prefers-color-scheme`）。色は `src/styles.css` の `:root` の変数にまとめ、ダークの値は UI §1 のトークンを使う
- グラフの色はモードごとに段を変え、それぞれの面の色で色覚の検証を通す
- トレイアイコン（Windows）は色の付いた四角に白い文字なので、タスクバーの明るさによらず同じものを使う

## 影響

- トレイ常駐の 3 ツール（Shelf、Clip、Meter）がそろって OS に合わせている。Standard 側を「トレイ常駐はテーマを OS に合わせる」に寄せるかは、desktop-platform で人が決める
