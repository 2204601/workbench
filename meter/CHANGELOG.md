# Changelog

リリースは GitHub Actions の meter ワークフローを `release` にチェックを入れて手動実行するか、`meter-v<バージョン>` のタグを push すると作成されます。本文はこのファイルの該当バージョンの節から取られます。

## 0.1.0

最初の版です。

### 変更点

- CPU・メモリ・ディスク・ネットワークの使用状況を、タスクトレイ（macOS はメニューバー）にいつも表示します
  - Windows では項目ごとに小さなアイコンが並び、値がアイコンに書かれます。CPU とメモリは、使用率が上がると背景が緑 → 黄 → 赤に変わります
  - macOS ではメニューバーに `CPU 12%  メモリ 54%` のように文字で並びます
  - 出す項目（最初は CPU とメモリ）と、更新の間隔（1 / 2 / 5 秒）は、アイコンの右クリックで選べます
- アイコンをクリックすると、直近 1 分のグラフ、コアごとの使用率、ドライブの空き容量、CPU やメモリを多く使っているアプリの上位 5 つが見られます
- ログイン時に起動、アプリ内アップデート
