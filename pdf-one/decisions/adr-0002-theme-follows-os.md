# ADR-0002：テーマは OS に合わせる

- 状態：採用
- 日付：2026-10-13
- 対象の Standard：UI §1（ダークを既定、ライトテーマは作らない）

## 背景

- PDF One はパソコンに詳しくない人が使う（`docs/UX.md` §1）。社内の PC はほぼ Windows のライトで、毎日使う Word・Excel・Acrobat もライト。黒い画面は「別のもの」に見えて、使う前に身構える
- 白いページを暗い枠で囲むと、紙とのコントラストが強く、長く見ると目が疲れるという声が 0.1 の試用であった
- トレイ常駐の Meter・Shelf・Clip は、同じ趣旨でテーマを OS に合わせている（それぞれの ADR-0001）

## 決定

- テーマは **OS の設定に合わせて** ライト / ダークを切り替える（`prefers-color-scheme`）。色は `src/index.css` の `:root` の変数にまとめ、ダークの値は UI §1 のトークン、ライトの値は文字のコントラストが WCAG AA（4.5 : 1）になるよう選ぶ
- 部品は Tailwind のユーティリティ（`bg-panel`、`text-dim`、`bg-hover`…）だけを使い、色の直書き（`bg-white/10`、`#141518`）をしない。ページの後ろの色（`bg-canvas`）、ファイルのタブの帯（`bg-tabbar`）もトークンにした
- ウィンドウの `theme` は指定せず OS に従う。読み込み前の背景色（`backgroundColor`）はライトのパネル色にする（利用者の大半がライトのため。ダークでは一瞬だけ明るい）
- 書き込みの色（マーカーの黄色、ペンの赤）は PDF に書く色なので、テーマで変えない

## 影響

- ウィンドウアプリでテーマを OS に合わせる最初のツール。Standard 側を「利用者が一般の社員のツールはテーマを OS に合わせる」に寄せるかは、desktop-platform で人が決める
- スクリーンショット（README、使い方）はライトで撮る
