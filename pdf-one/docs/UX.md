# UI / UX の方針

PDF One の画面の決まり。**編集するためのアプリ** として作り、**パソコンに詳しくない人** が説明なしに使えることを目指す。機能の振る舞いは [SPEC.md](SPEC.md)、機能を足す順番は [ROADMAP.md](ROADMAP.md)。画面を足す・変えるときは、先にここを読む。

## 1. 誰が使うか

社内のほぼ全員（Windows が中心）。Word と Excel は毎日使うが、PDF は「見るもの」で、編集は Acrobat を持っている人に頼んでいる。ショートカットは覚えない。右クリックを使わない人もいる。英語や PDF の用語が出ると止まる。

想定する 3 人（利用者テスト（§11）で確かめて直す）：

| | 仕事 | PDF ですること | 困っていること |
|---|---|---|---|
| A | 事務 | 請求書や見積書に印鑑を押す、ページを抜き出す、メールで送るために小さくする | 「注釈」「スタンプ」の意味が分からない。保存したら元のファイルが変わってしまわないか不安 |
| B | 営業 | 取引先からの申込書に記入して返す | 入力欄の無い PDF は印刷して手で書いてスキャンしている |
| C | 総務・管理 | 契約書の文字を 1 か所直す、黒塗りして出す、パスワードをかけて送る | Acrobat Pro が 1 本しかなく順番待ち |

## 2. 原則

1. **開いたらすぐ編集できる**。「編集モードに入る」ボタンは無い。見るだけのときも同じ画面
2. **ボタンには言葉を付ける**。主な操作をアイコンだけのボタンにしない
3. **日常の言葉で書く**。PDF の用語（注釈、AcroForm、墨消し、レンダリング）を画面に出さない（§3）
4. **一度に見せるのは 1 つの仕事の道具だけ**。作業タブ（§5）で切り替える。1 つのタブに置くボタンは 10 個まで
5. **いま何の状態かを常に書いておく**。道具を持っているあいだ、画面の下に「いま：マーカー。文字をなぞると引けます」と出す
6. **間違えても戻れる**。「元に戻す」は常に見える。元のファイルは黙って変えない。消す前に何が消えるか分かる
7. **次に何をするかを画面が教える**。空の状態、初めての操作、終わった後に、短い案内を出す（§9）
8. **操作は直接**。ページの上のものはクリックで選び、ドラッグで動かし、ハンドルで大きさを変え、ダブルクリックで中身を直す。選んだものの近くに、できることの小さなメニューを出す
9. **キーボードは近道であって、前提にしない**。マウスだけで全部できる。右クリックメニューは補助で、同じことがボタンでもできる
10. **見やすさ**。文字は 14px 以上、押せるものは 32px 以上、OS の明暗に合わせる、色だけで意味を伝えない（§10）

## 3. 言葉

ボタンの言葉は 2〜7 文字。補足はツールチップと画面の下の案内で。知っている人向けに、Acrobat の言い方をツールチップに添える（例：「黒塗り（Acrobat の墨消し）」）。

| 画面に出す言葉 | 使わない言葉 | 備考 |
|---|---|---|
| 書き込み | 注釈、アノテーション、マークアップ | 作業タブの名前。コメント一覧も「書き込みの一覧」 |
| マーカー / 下線 / 取り消し線 | ハイライト | |
| 文字を置く | テキストボックス、FreeText | 「文字を置く」= ページの上に新しく書く。「文字を直す」= もともとある文字を変える |
| 文字を直す | テキストの編集、コンテンツ編集 | |
| 白で消す | ホワイトアウト | 「消して、上から書く」 |
| 付箋 | ノート、コメント注釈 | 付箋に書く文章は「コメント」 |
| ペン / 消しゴム | インク、フリーハンド | |
| 図形（四角、丸、線、矢印、吹き出し） | 矩形、楕円、ポリゴン、コールアウト | |
| 印鑑・画像 | スタンプ | 社判、日付印、署名の画像 |
| 入力と署名 | フォーム、フィールド、Fill & Sign | 入力欄の無い PDF にも記入できる |
| 入力欄を作る | フォーム作成 | |
| ページを整理 | サムネイル、オーガナイザー | |
| つなげる | 結合、マージ、インサート | ツールチップに「結合」を添える |
| 小さくする | 圧縮、最適化、ダウンサンプル | 「メールで送れる大きさにする」 |
| パスワードをかける / 外す | 暗号化、セキュリティ、権限 | |
| 黒塗り | 墨消し、リダクション | ツールチップに「墨消し」を添える |
| 文字を読み取る | OCR、テキスト認識 | 「スキャンした PDF の文字を探せるようにする」 |
| 元に戻す / やり直す | アンドゥ、リドゥ | |
| 保存 / 名前を付けて保存 | 書き出し、エクスポート | PDF のまま保存するとき。別の形式にするときは「変換」 |
| 表示のみ | 読み取り専用 | 保護された PDF など |
| 濃さ | 不透明度 | 薄い ─ 濃い |

## 4. 画面の構成

Word に似せる。Word なら触れる人が多い。

```
┌──────────────────────────────────────────────────────────────────────┐
│ [見積書.pdf ●] [契約書.pdf] [+]                                        │ ファイルのタブ
├──────────────────────────────────────────────────────────────────────┤
│ ホーム │ 書き込み │ 文字と画像 │ ページ │ 入力と署名 │ 保護 │ 変換   何をしますか 🔍 │ 作業タブ
├──────────────────────────────────────────────────────────────────────┤
│ [開く] [保存] [印刷] │ [元に戻す] [やり直す] │ [選択] [マーカー] [文字を置く] [印鑑] │ [検索] │ 道具（絵＋言葉）
├──────────┬───────────────────────────────────────────┬───────────────┤
│ ページ   │                                           │ 選んだもの     │
│ 書き込み │                                           │  マーカー      │
│ しおり   │                  ページ                    │  色  ● ● ● ●   │
│          │                                           │  濃さ ───●──   │
│ (一覧)   │                                           │  コメント      │
│          │                                           │  [複製] [削除] │
├──────────┴───────────────────────────────────────────┴───────────────┤
│ いま：マーカー。文字をなぞると引けます。終わるには「選択」   3 / 12 ページ  [−] 100% ▾ [+]  │ 案内と状態
└──────────────────────────────────────────────────────────────────────┘
```

| 部分 | 役割 | 決まり |
|---|---|---|
| ファイルのタブ | 開いているファイル。未保存は ●、保護されたものは「表示のみ」。「+」は、起動したときと同じ「はじめる」の画面（開く、最近のファイル）を新しいタブで出す。ファイルの選択画面は、その中の「開く」から | 今のまま |
| 作業タブ | 仕事の種類。選ぶと下の道具が変わる | 7 つ（§5）。右端に「何をしますか」（§9） |
| 道具 | アイコンの下に言葉。高さ 56px、幅 56px 以上。押している道具は色が付く | 1 タブ 10 個まで、グループは 4 つまで。横幅が足りなければアイコンの横に言葉（高さ 32px） |
| 左の一覧 | ページ、書き込み、しおり | 右の端をドラッグで幅を変えられる。下の行の「一覧」ボタンで出し入れ。一覧の上に言葉付きの小さなボタン（ページ：回転・削除・足す）。右クリックが無くても同じことができる |
| ページ | 文書そのもの | 選んだものの近くに小さなメニュー（コピー、マーカー、文字を直す、黒塗り…） |
| 右の「詳細」 | 選んだもの、またはこれから置くものの設定。文書の情報 | 幅 240px（左の端をドラッグで変えられる）。言葉付きの項目を縦に並べる（§7）。閉じられ、下の行の「詳細」ボタンで戻せる。何も選んでいなければ案内と文書の情報 |
| 案内と状態 | 左：いま何の状態か、次に何をするか。右：ページ番号と拡大縮小 | 常に出す。文字 12px 以上 |

- ズームとページ番号はツールバーから下へ移す。上は編集の道具に使う
- 「ページを整理」（全ページの並び）は「ページ」タブの「すべてのページを並べる」で全面に出す。今の Organizer のまま
- ウィンドウの最小は 960 × 600。社内のノート PC（1366 × 768、拡大 125%）で全部のタブが収まることを確かめる
- メニューバー（OS 標準）とショートカットは今のまま残す。道具に無いもの（ログ、バックアップのフォルダ、ショートカット一覧）はメニューだけ

## 5. 作業タブ

| タブ | 道具（左から） | 版 |
|---|---|---|
| ホーム | 開く、保存、印刷 ｜ 元に戻す、やり直す ｜ 選択、マーカー、文字を置く、印鑑 ｜ 検索 | 0.2 |
| 書き込み | 選択、マーカー、下線、取り消し線 ｜ 文字を置く、付箋、ペン、消しゴム ｜ 図形 ▾（四角、丸、線、矢印、吹き出し）、印鑑・画像 ▾（ライブラリ、日付印、文字の印、ファイルから） | 0.2（吹き出しは 0.3） |
| 文字と画像 | 文字を直す、白で消す、文字を置く ｜ 画像を置く、画像を差し替える ｜ ヘッダー・フッター、ページ番号、透かし ｜ リンク | 0.3 |
| ページ | すべてのページを並べる ｜ 右に回転、左に回転、削除 ｜ 白紙を足す、ファイルから足す、複製 ｜ 抜き出す、分割、余白を切る | 0.2（複製・余白を切るは 0.3） |
| 入力と署名 | 記入（文字）、✓、✗、●、線、日付 ｜ 署名 ▾（手書き、ライブラリ、画像から） ｜ 入力欄を作る ｜ 入力内容を消す | 0.2（入力欄を作るは 0.6） |
| 保護 | パスワードをかける、パスワードを外す ｜ 黒塗り、隠れた情報を取り除く ｜ 電子署名、署名を確かめる | 0.5 |
| 変換 | つなげる、画像から PDF、Word から PDF ｜ 小さくする、文字を読み取る ｜ 画像にする、Word にする、文字だけ取り出す ｜ 2 つを比べる | 0.4（比べるは 0.6） |

- まだ無い機能のボタンは **置かない**（押せないボタンを並べて落胆させない）。版が進んで足す
- 表示の設定（2 ページ、回転して見る、全画面）は右下の拡大縮小のメニューと「表示」メニューに置く。編集の道具と混ぜない
- 開いたときは「ホーム」。タブは前回のものを覚えない（次に開くときも同じ場所にある方が迷わない）

## 6. 道具の振る舞い

- 道具を選ぶと、ボタンが押された色になり、ポインタが変わり、下の案内が変わる
- **1 回置いたら「選択」に戻る**：文字を置く、付箋、図形、印鑑・画像、記号、日付。「詳細」に「続けて置く」のチェックがあり、入れると戻らない
- **続けて使う**：マーカー、下線、取り消し線、ペン、消しゴム。終わるには「選択」を押すか Esc。案内に書いておく
- 選択：クリックで選ぶ。ドラッグで動かす。ハンドルで大きさ。ダブルクリックで中身（文字、コメント）を直す。Delete で消す。選んだものの近くに小さなメニュー
- 文字をなぞって選ぶと、小さなメニュー（コピー、マーカー、下線、取り消し線、文字を直す（0.3）、黒塗り（0.5））
- 何かを消したら、トーストに「元に戻す」（ページの削除は今もそう）
- 確認を出すのは、戻せないことだけ：元のファイルへの上書き（ファイルごとに最初の 1 回）、黒塗りの確定、署名が無効になる保存、保存せずに閉じる。確認には **何が起きるか** と **戻せるか** を書く
- ショートカットはツールチップに添える（「マーカー（M）」）。覚えなくても困らない

## 7. 詳細（右）

| 選んでいるもの | 出すもの |
|---|---|
| 何も無い | 「ページの上のものをクリックすると、ここで色や大きさを変えられます」、文書の情報（ページ数、用紙、ファイルの大きさ、保護・署名・入力欄の有無） |
| 道具を持っている | 「これから置くもの：文字」と、その設定 |
| 書き込み | 「選んだもの：マーカー」。色（8 色＋ほかの色）、塗り、太さ、文字の大きさ、濃さ。コメント欄。作成者と日時。複製、最前面へ、削除 |
| ページ（左の一覧で） | ページ番号と用紙。回転、削除、複製、抜き出す |
| 文字（文字を直す） | フォントの置き換えの知らせ、大きさ、色、そろえ |

- 項目は言葉を上、操作を下に縦に並べる（細い帯に詰めない）
- スライダーには数字も出す。数字は打てる
- 色は丸い見本で、選んでいるものに枠。「ほかの色」は OS の色の選択

## 8. 保存と安全

- 保存を押したとき、そのファイルでまだ一度も保存していなければ、先に **どちらにするか** を聞く：
  - **新しいファイルとして保存（おすすめ）**：元のファイルはそのまま。名前は `<元の名前>_編集.pdf` を提案
  - **元のファイルに上書き**：前の版はバックアップに残る（30 個。「バックアップを開く」で戻せる）
  - 2 回目からは聞かずに同じ場所へ
- 保存の状態を案内の行とタブに出す：「保存しました 10:32」「変更あり（保存していません）」
- **下書きの自動保存**：30 秒ごとに編集の内容（ページの並び、書き込み、入力した値）をアプリのデータフォルダの `drafts/` に書く。元のファイルは触らない。次に起動したとき「前回、保存していない変更があります」→「戻す / 捨てる」。元のファイルが変わっていれば戻せないと伝える
- 閉じるとき、保存していなければ「保存する / 保存しない / キャンセル」（今のまま）
- 開いたときに分かることは、その場で伝える：「この PDF は画像だけです。文字を読み取ると、探したりコピーしたりできます」「入力欄があります。クリックして入力できます」「パスワードで保護されています。表示だけできます」「電子署名があります。保存すると署名が無効になります」

## 9. 案内と助け

- **スタート画面**：「PDF を開く」（大きく）、「新しく作る」（白紙、画像から、ファイルをつなげる。0.4）、最近のファイル（1 ページ目の絵、名前、日付）、「使い方」
- **初回の案内**：1 度に 1 つ、全部で 3 つまで。「上のタブで作業を選びます。まず『書き込み』を押してみてください」「ページの上のものはクリックして選べます」「保存すると、元のファイルは残ります」。「わかった」で消え、設定に記録する
- **何をしますか**：作業タブの右端の検索欄。「ハンコ」「黒塗り」「小さく」「結合」と打つと、合う道具が言葉で並ぶ。選ぶとその道具になる（タブが切り替わり、ボタンが光る）。言い換え（ハンコ＝印鑑、結合＝つなげる、圧縮＝小さくする、OCR＝文字を読み取る）はコマンド表に持つ
- **使い方**：アプリの中の 1 画面 1 作業の説明（3〜5 手順と絵）。外のサイトに飛ばさない
- **空の状態**：書き込みの一覧が空なら「まだ書き込みがありません。『書き込み』タブのマーカーや付箋で書くと、ここに並びます」
- **エラー**：「〜できませんでした。〜してください」の形。原因と次の手を 1 行ずつ。技術的な文言は「詳細」を開いたときだけ
- **長い処理**：進み具合と「中止」。終わったらトーストで結果と次の手（「保存しました。フォルダを開く」）

## 10. 見た目

- **テーマは OS に合わせる**（ライト / ダーク）。Word、Excel、Acrobat はライトで、社内の PC もほぼライト。Platform UI §1（ダーク既定）からの逸脱になるので ADR を残す（[ROADMAP](ROADMAP.md) の判断 2）
- 文字：本文 14px、ボタンの言葉 12px 以上、案内 12px 以上。設定に「文字を大きく」（1.15 倍、1.3 倍）
- 押せるものは 32px 以上。道具のボタンは 56px
- コントラストは WCAG AA（文字 4.5 : 1）。押せないものも読める（3 : 1）
- 選んだものは枠と背景の両方で示す。エラーは色だけでなくアイコンと文
- キーボードで動かしたときのフォーカスの枠を出す
- アニメーションは短く、OS の「動きを減らす」に従う（今のまま）

## 11. 確かめ方

版を出す前に、**説明なしで使えるか** を人で確かめる。

- 3〜5 人（§1 の A・B・C に近い人）。見ている人は手伝わず、迷った場所と口にした言葉を記録する
- 代表タスク（0.2）：
  1. この PDF の 3 ページ目を消して、新しい名前で保存する
  2. ここに印鑑を押して保存する
  3. 「合計」の行にマーカーを引いて、付箋に「要確認」と書く
  4. 入力欄の無い申込書に、名前と日付を書き入れる
  5. 2 つの PDF を 1 つにつなげる（0.4 まではページの挿入で）
  6. 両面で印刷する
  - 版が進んだら足す：文字を 1 か所直す（0.3）、小さくしてメールに添付する（0.4）、名前を黒塗りする（0.5）、パスワードをかける（0.5）
- 合格：各タスクを 5 人中 4 人が **3 分以内に助けなしで** 終える。元のファイルが壊れる・保存したつもりが保存されていない、が 0 件
- 結果は `docs/usability/<版>.md` に残し、迷った場所は次の版で直す
