## 候補

| | 内容 | メモ |
|---|---|---|
| 印刷 | ⌘P でページを印刷 | WebView の印刷か、OS の印刷ダイアログへ PDF を渡す方法かを比べる |
| もとの文字の編集 | PDF にある文字を直接書き換える | PDF は「文字の位置と字形」しか持たず、同じフォントのグリフが無いことも多い。まずは「白で消して上から書く」（ホワイトアウト＋テキストボックス）を道具として入れ、本当の編集はその後 |
| 墨消し | 選んだ範囲の文字と画像をページから本当に消す | 見た目を黒く塗るだけでは中身が残る。コンテンツストリームの書き換えが要る |
| OCR | スキャン PDF に文字の層を足して、検索とコピーをできるように | macOS は Vision、Windows は Windows.Media.Ocr（OS の機能）。純 Rust のモデルは入れない |
| 日付印・社判の作成 | 日付入りの丸い印をその場で作る | 画像のライブラリの延長 |
| 手書き署名の保存 | ペンで書いた署名をライブラリに入れる | Ink を画像にするか、Ink のまま持つか |
| サムネイルに注釈 | サイドバーとページの整理のサムネイルに、書いた注釈も描く | 今は PDF の中身だけ |
| ページの複製・ページ番号・透かし・ヘッダー | Acrobat の「ページを整理」「透かし」 | compose.rs に足す |
| 圧縮 | 画像を縮めてファイルを小さく | |
| パスワードの設定・解除 | 保護を付ける、外す（パスワードを知っている場合） | lopdf の暗号化 |
| 2 ページ表示、プレゼンテーション | | Viewer のレイアウト |
| 電子署名を保つ保存 | 署名済みの PDF に注釈を足しても署名が壊れない（増分保存） | lopdf は全体を書き直すので、追記の書き出しを自前で |
| 比較 | 2 つの版の違い | |
