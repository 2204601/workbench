# 機能仕様

PDF One 0.1 の振る舞い。設計の境界は [ARCHITECTURE.md](ARCHITECTURE.md)、これからは [ROADMAP.md](ROADMAP.md)。

## 1. 方針

- 目標は Acrobat。0.1 は **閲覧＋ページ編集、注釈・書き込み、フォーム入力**（利用者と相談して決めた。2026-10-13）
- **元のファイルを黙って書き換えない**。最初の保存は別名（`<元の名前>_編集.pdf`、元と同じフォルダ）を提案する。上書きを選んだときは、上書きする前の版をバックアップに残す（§6）
- 書いたものは PDF の **標準の注釈** として保存する。Acrobat や Edge、Chrome、プレビューでも同じに見え、Acrobat で続きを編集できる。ページの中身（コンテンツストリーム）は書き換えない
- 通信しない（アップデートの確認だけ）。ファイルの中身をログに出さない

## 2. 開く

- ⌘O（複数選べる）、ウィンドウへのドロップ、「このアプリで開く」、ダブルクリック（2 つ目の起動は今のウィンドウのタブになる）、スタート画面の「最近使ったファイル」（12 件）
- 開いているファイルをもう一度開くと、そのタブが前に出る
- 中身で PDF かどうかを判定する（拡張子ではなく）。1 GB を超えるものは開かない
- **表示だけ** になるもの（理由をトーストで伝え、タブに「表示のみ」）：
  - パスワードや権限で保護された PDF（パスワードを聞いて表示はする）
  - XFA フォーム（Acrobat で開くよう伝える）
  - 編集用に読み込めない、壊れた PDF（pdf.js で表示できれば表示する）
- 電子署名のある PDF は開けるが、保存すると署名が無効になることを伝え、保存の前にも確認する

## 3. 見る

- ページは縦に連続して並ぶ。ズーム：幅に合わせる（既定）・ページ全体・10%〜640%。⌘ + ホイール（トラックパッドのピンチ）でポインタの位置を中心に拡大縮小
- 手のひらツール（H）、スペースを押しながらドラッグ、中ボタンのドラッグで動かす
- サイドバー（F4）：ページのサムネイル、コメント（注釈の一覧。選ぶとそのページへ、コメントを書ける）、しおり（PDF の目次）
- 文字の選択とコピー。選ぶと小さなメニュー（マーカー・下線・取り消し線・コピー）が出る
- リンク：文書の中はそのページへ。Web のリンクは確認してからブラウザで開く（`http`、`https`、`mailto` だけ）

## 4. 検索

- ⌘F で検索欄。入力が止まって 0.25 秒で全ページを探す（見つかった分から見せる）。今のページから先の最初の結果へ移る
- Enter / ⌘G で次、⇧Enter / ⌘⇧G で前。Esc で閉じる
- 大文字と小文字、全角と半角（NFKC）、空白（日本語の字間の空白や行末）の違いは無視する
- 文字の無いスキャン PDF は探せない（OCR は [ROADMAP](ROADMAP.md)）

## 5. ページの整理

サイドバーのサムネイルと「ページを整理」（⌘⇧O、全画面のサムネイルの並び）で同じことができる。対象は選んだページ、選んでいなければ今のページ。

| 操作 | |
|---|---|
| 選ぶ | クリック、⌘ / Ctrl＋クリックで追加、⇧＋クリックで範囲、⌘A ですべて |
| 並べ替え | ドラッグ（選んだページをまとめて動かす） |
| 回転 | 右 / 左に 90°（⌘⇧R / ⌘⇧L） |
| 削除 | Delete。すべてのページは消せない。トーストの「元に戻す」で戻せる |
| 白紙を挿入 | 今のページの後ろに、今のページと同じ大きさで |
| ファイルから挿入 | 別の PDF のページを今のページの後ろに（結合）。サイドバーやページの整理へのドロップでも。保護された PDF は挿入できない |
| 書き出す | 選んだページを新しい PDF に（抽出）。今のタブは変わらない |
| 分割 | N ページずつ別のファイルにして、選んだフォルダへ（`<名前>_p1-3.pdf`…） |

ページの変更は元に戻せる。保存するまでファイルは変わらない。

## 6. 注釈

| ツール | キー | 操作 | PDF の注釈 |
|---|---|---|---|
| マーカー / 下線 / 取り消し線 | M / U / K | 文字を選ぶ。文字の無いところはドラッグした範囲 | Highlight / Underline / StrikeOut |
| テキスト | T | クリック（幅 180pt）かドラッグで枠を作って入力。改行と折り返しは画面のとおりに保存。入力に合わせて下へ伸びる。ダブルクリックで編集 | FreeText |
| 付箋 | N | クリックで置いてコメントを入力 | Text |
| ペン | P | ドラッグで描く。1.5 秒以内に続けて描いた線は 1 つの注釈になる（署名など） | Ink |
| 四角形 / 楕円 / 直線 / 矢印 | R / O / L / A | ドラッグ（⇧ で正方形・正円・45° 刻み）。クリックだけなら決まった大きさ | Square / Circle / Line |
| 画像・印鑑 | I | 画像を選んで、クリック（長い辺 3 cm）かドラッグで置く。縦横比は保つ | Stamp |

- 選択ツール（V）でクリックすると選べる。ドラッグで移動、ハンドルで大きさ（直線と矢印は両端）。矢印キーで 1pt（⇧ で 10pt）動かす。Delete で削除、⌘C / ⌘V で複製（今のページへ、少しずらして）
- 選んだ注釈とツールの見た目は、ツールバーの下の帯で変える：色、塗り（四角形・楕円・テキスト）、太さ・枠線、文字の大きさ（テキスト）、不透明度。ツールごとに次回も同じ見た目になる
- 回転したページにテキストや画像を置くと、画面で読める向きになる
- 作成者名（設定、空ならパソコンのユーザー名）と日時を記録する
- 開いた PDF にある注釈のうち、上の種類で、点線・雲形の枠や吹き出し線、返信（スレッド）、非表示の無いものは、自分で書いたものと同じように編集できる。それ以外（リンク、ほかのアプリのスタンプなど）はそのまま残して表示する

### 画像・印鑑

- PNG と JPEG。ファイルを選ぶ、ページへのドロップ、⌘V（クリップボードの画像）
- ライブラリ：よく使う画像を入れておき、どの文書でも使える。アプリのデータフォルダの `stamps/` に置く
- 長い辺が 2400px を超える画像は縮めて埋め込む（JPEG はそのまま入れる）。40 MB を超える画像は読まない

## 7. フォーム

- PDF の入力欄（テキスト、チェックボックス、ラジオボタン、コンボボックス、リスト）にそのまま入力する（pdf.js のフォーム層）
- 保存すると値（/V）を書き、テキストと選択肢の見た目を日本語フォントで作り直す。欄の書式（/DA）は変えない
- 計算や書式の JavaScript は動かさない

## 8. 保存

- ⌘S：まだ保存していないタブは保存先を聞く（`<元の名前>_編集.pdf` を提案）。一度保存したら同じ場所へ黙って保存する
- ⌘⇧S：名前を付けて保存
- 保存先にファイルがあれば、上書きする前にバックアップ（新しい 30 個）へコピーする
- 書き込みは同じフォルダの一時ファイルから入れ替える。途中で失敗しても元のファイルは壊れない
- ほかのアプリで開いていて書けないときは、そう伝える
- タブやウィンドウを閉じるとき、保存していない変更があれば「保存 / 保存しない / キャンセル」を聞く

## 9. 日本語の文字

テキストボックスとフォームの文字は、パソコンの日本語フォントを PDF に埋め込む（使った文字だけ）。

| OS | フォント（見つかった最初のもの） |
|---|---|
| Windows | 游ゴシック、メイリオ、BIZ UD ゴシック、MS ゴシック |
| macOS | ヒラギノ角ゴシック W3、ヒラギノ角ゴ（GB）、Osaka |

画面のテキストボックスも同じフォントで描き、行の折り返しを画面と同じにする。見つからないときは Helvetica になり、日本語は書けない（設定画面に出る）。
