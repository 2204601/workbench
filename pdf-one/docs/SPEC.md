# 機能仕様

PDF One の振る舞い（0.2 の途中）。設計の境界は [ARCHITECTURE.md](ARCHITECTURE.md)、画面の決まりは [UX.md](UX.md)、これからは [ROADMAP.md](ROADMAP.md)。

## 1. 方針

- 目標は Acrobat。0.1 は **閲覧＋ページ編集、注釈・書き込み、フォーム入力**（利用者と相談して決めた。2026-10-13）。0.2 は画面を **編集するためのもの** に作り直す（§10、[UX.md](UX.md)）
- 画面に出す言葉は [UX.md](UX.md) §3 の表に従う（注釈 → 書き込み、スタンプ → 印鑑、テキスト → 文字を置く…）。この文書では PDF の用語（注釈）も併記する
- **元のファイルを黙って書き換えない**。最初の保存は別名（`<元の名前>_編集.pdf`、元と同じフォルダ）を提案する。上書きを選んだときは、上書きする前の版をバックアップに残す（§6）
- 書いたものは PDF の **標準の注釈** として保存する。Acrobat や Edge、Chrome、プレビューでも同じに見え、Acrobat で続きを編集できる。ページの中身（コンテンツストリーム）は書き換えない
- 通信しない（アップデートの確認だけ）。ファイルの中身をログに出さない

## 2. 開く

- ⌘O（複数選べる）、ウィンドウへのドロップ、「このアプリで開く」、ダブルクリック（2 つ目の起動は今のウィンドウのタブになる）、スタート画面の「最近使ったファイル」（12 件）
- 開いているファイルをもう一度開くと、そのタブが前に出る
- 中身で PDF かどうかを判定する（拡張子ではなく）。1 GB を超えるものは開かない
- **表示だけ** になるもの（理由をトーストで伝え、タブに「表示のみ」）：
  - パスワードや権限で保護された PDF（パスワードを聞いて表示はする）
  - XFA フォーム（Acrobat で開くよう伝える）
  - 編集用に読み込めない、壊れた PDF（pdf.js で表示できれば表示する）
- 電子署名のある PDF は開けるが、保存すると署名が無効になることを伝え、保存の前にも確認する
- 開いたとき、最初の 3 ページを見て伝える：文字が無ければ「この PDF は画像だけです」（検索やコピーはできない、マーカーはドラッグで囲む）、入力欄があれば「入力欄があります」

## 3. 見る

- ページは縦に連続して並ぶ。ズーム：幅に合わせる（既定）・ページ全体・10%〜640%。⌘ + ホイール（トラックパッドのピンチ）でポインタの位置を中心に拡大縮小
- 手のひらツール（H）、スペースを押しながらドラッグ、中ボタンのドラッグで動かす
- **回転して見る**（右下のボタン、表示メニュー）：すべてのページを画面の上だけで 90° 回す。ファイルは変わらない。回した向きで文字や印鑑を置くと、その向きで正立する
- 左の一覧（F4）：ページのサムネイル（上に回転・削除・足すのボタン）、書き込み（注釈の一覧。選ぶとそのページへ、コメントを書ける）、しおり（PDF の目次）
- 文字の選択とコピー。選ぶと小さなメニュー（マーカー・下線・取り消し線・コピー）が出る
- リンク：文書の中はそのページへ。Web のリンクは確認してからブラウザで開く（`http`、`https`、`mailto` だけ）

## 4. 検索

- ⌘F で検索欄。入力が止まって 0.25 秒で全ページを探す（見つかった分から見せる）。今のページから先の最初の結果へ移る
- Enter / ⌘G で次、⇧Enter / ⌘⇧G で前。Esc で閉じる
- 大文字と小文字、全角と半角（NFKC）、空白（日本語の字間の空白や行末）の違いは無視する
- 文字の無いスキャン PDF は探せない（OCR は [ROADMAP](ROADMAP.md)）

## 5. ページの整理

左の一覧のサムネイルと「すべてのページを並べる」（⌘⇧O、全画面のサムネイルの並び。「ページ」タブ）で同じことができる。対象は選んだページ、選んでいなければ今のページ。

| 操作 | |
|---|---|
| 選ぶ | クリック、⌘ / Ctrl＋クリックで追加、⇧＋クリックで範囲、⌘A ですべて |
| 並べ替え | ドラッグ（選んだページをまとめて動かす） |
| 回転 | 右 / 左に 90°（⌘⇧R / ⌘⇧L） |
| 削除 | Delete。すべてのページは消せない。トーストの「元に戻す」で戻せる |
| 白紙を足す | 今のページの後ろに、今のページと同じ大きさで |
| ファイルからページを足す | 別の PDF のページを今のページの後ろに（結合）。一覧や「すべてのページ」へのドロップでも。保護された PDF は足せない |
| 抜き出す | 選んだページを新しい PDF に（抽出）。今のタブは変わらない |
| 分割 | N ページずつ別のファイルにして、選んだフォルダへ（`<名前>_p1-3.pdf`…） |

ページの変更は元に戻せる。保存するまでファイルは変わらない。

## 6. 注釈

| ツール | キー | 操作 | PDF の注釈 |
|---|---|---|---|
| マーカー / 下線 / 取り消し線 | M / U / K | 文字を選ぶ。文字の無いところはドラッグした範囲 | Highlight / Underline / StrikeOut |
| 文字を置く | T | クリック（幅 180pt）かドラッグで枠を作って入力。改行と折り返しは画面のとおりに保存。入力に合わせて下へ伸びる。ダブルクリックで編集 | FreeText |
| 付箋 | N | クリックで置いてコメントを入力 | Text |
| ペン | P | ドラッグで描く。1.5 秒以内に続けて描いた線は 1 つの注釈になる（署名など） | Ink |
| 四角 / 丸 / 線 / 矢印 | R / O / L / A | ドラッグ（⇧ で正方形・正円・45° 刻み）。クリックだけなら決まった大きさ | Square / Circle / Line |
| 印鑑・画像 | I | 画像を選んで、クリック（長い辺 3 cm）かドラッグで置く。縦横比は保つ | Stamp |
| 日付印 / 文字の印 | — | ダイアログで作って（§6 印鑑）、クリックで置く。線と文字で描く（画像ではない） | Stamp（/Name PDFOneSeal） |
| 消しゴム | E | ペンの線の上をなぞると、その線が消える（1 本ずつ。最後の線が消えれば注釈ごと）。1 回のドラッグが 1 つの取り消し単位 | — |

- **1 回置いたら「選択」に戻る**：文字を置く（入力が終わったとき）、四角・丸・線・矢印、印鑑・画像、付箋。「詳細」の「続けて置く」を入れると戻らない（付箋は除く。コメントを書くので毎回「選択」に戻る）。マーカー・下線・取り消し線・ペン・手のひらは続けて使え、「選択」を押すか Esc で終わる
- 選択ツール（V）でクリックすると選べる。ドラッグで移動、ハンドルで大きさ（線と矢印は両端）。矢印キーで 1pt（⇧ で 10pt）動かす。Delete で削除、⌘D で複製、⌘C / ⌘V でも複製（今のページへ、少しずらして）
- 選んだ注釈とツールの見た目は、右の「詳細」で変える：色、塗り（四角・丸・文字）、太さ・枠線、文字の大きさ、濃さ（不透明度）、コメント。複製・最前面へ・削除のボタンもある。ツールごとに次回も同じ見た目になる
- 回転したページにテキストや画像を置くと、画面で読める向きになる
- 作成者名（設定、空ならパソコンのユーザー名）と日時を記録する
- 開いた PDF にある注釈のうち、上の種類で、点線・雲形の枠や吹き出し線、返信（スレッド）、非表示の無いものは、自分で書いたものと同じように編集できる。それ以外（リンク、ほかのアプリのスタンプなど）はそのまま残して表示する

### 画像・印鑑

- PNG と JPEG。ファイルを選ぶ、ページへのドロップ、⌘V（クリップボードの画像）
- ライブラリ：よく使う画像を入れておき、どの文書でも使える。アプリのデータフォルダの `stamps/` に置く
- 長い辺が 2400px を超える画像は縮めて埋め込む（JPEG はそのまま入れる）。40 MB を超える画像は読まない

### 印鑑（日付印・文字の印）

- **日付印**：上の文字（部署など）・日付・下の文字（名前）の 3 段の丸い印。日付は西暦（2026.10.13）か令和（令和8.10.13）を選べ、手で直せる。大きさは 18 / 24 / 30 mm、色は赤・青・黒。文字の大きさは直径の 0.38 倍
- **文字の印**：承認済み・社外秘・受領・コピー・回覧・至急・済・控・見本・重要、またはほかの言葉を枠で囲む。文字の大きさは小・中・大
- 画像ではなく線と文字で描く（Rust `annots.rs`、画面は `lib/seal.ts`。文字の置き方は同じ規則）。埋め込みフォントで書くので拡大してもきれい。置いたあとも「詳細」で文字・色・太さ・大きさを直せる。帯より長い言葉は縮めて収める
- PDF には /Stamp（/Name PDFOneSeal）として標準の見た目付きで書き、/PDFOneStyle の `seal` で読み戻す。ほかのビューアでは見た目どおりに表示される（文字は変えられない）

## 7. 入力と署名

入力欄の無い PDF（印刷して手で書いていたもの）に、そのまま書き入れる。すべて §6 の注釈として保存するので、Acrobat でも見える。

| 道具 | 置くもの | PDF の注釈 |
|---|---|---|
| 記入 | 枠なし・塗りなしの文字（11pt、黒）。クリックして入力。入力が終わると「選択」に戻る | FreeText |
| チェック / バツ | ✓ / ✗ の線（14pt、1.5pt、黒）。クリックで置く | Ink |
| 黒丸 | 塗りつぶした丸（7pt） | Circle |
| 横線 | 20pt の線（空欄の取り消しなど） | Line |
| 日付 | 今日の日付（2026/10/13）の文字。ダブルクリックで直せる | FreeText |
| 署名 ▾ | 手書きの署名を作る（マウスかペンで書く → 透明な PNG にしてライブラリへ → 置く）、ライブラリから置く、画像ファイルから | Stamp |

- 記号と日付は、置くと「選択」に戻る（「続けて置く」で戻らない）。色だけ変えられる
- 手書きの署名は、画面の 2 倍の解像度で、線の周りを 8px 残して切り出す。ライブラリでの名前は「署名」

## 8. フォーム

- PDF の入力欄（テキスト、チェックボックス、ラジオボタン、コンボボックス、リスト）にそのまま入力する（pdf.js のフォーム層）
- 保存すると値（/V）を書き、テキストと選択肢の見た目を日本語フォントで作り直す。欄の書式（/DA）は変えない
- 計算や書式の JavaScript は動かさない

## 9. 保存

- ⌘S：まだ保存していないタブは、先に **保存のしかた** を聞く：「新しいファイルとして保存（おすすめ）」（保存先を聞く。`<元の名前>_編集.pdf` を提案）か「元のファイルに上書き」（聞かずに元の場所へ。前の版はバックアップに残る）。一度保存したら同じ場所へ黙って保存する
- ⌘⇧S：名前を付けて保存（保存のしかたは聞かず、保存先だけ聞く）
- 保存先にファイルがあれば、上書きする前にバックアップ（新しい 30 個）へコピーする
- 書き込みは同じフォルダの一時ファイルから入れ替える。途中で失敗しても元のファイルは壊れない
- ほかのアプリで開いていて書けないときは、そう伝える
- タブやウィンドウを閉じるとき、保存していない変更があれば「保存 / 保存しない / キャンセル」を聞く

### 下書き

- 30 秒ごとに、保存していないタブの状態（ページの並び、書き込み、入力した値、元のファイルの場所、使った画像）をアプリのデータフォルダの `drafts/<ファイルの場所のハッシュ>/` に書く。変わっていなければ書かない。元のファイルは触らない
- 次に起動したとき、下書きがあれば「前回、保存していない変更があります」と聞く。「戻す」で元のファイルを開き直して続きから（未保存のタブになる）、「捨てる」で消す、「あとで決める」で次回また聞く。元のファイルが無いか表示だけなら戻せないと伝える
- 保存したとき、「保存しない」で閉じたときに、そのタブの下書きを消す

## 10. 印刷

- ⌘P、ホームの「印刷」、ファイルメニュー。印刷するページ（すべて・いまのページ・「1-3, 5」で指定）、用紙（A4・A3・B5・B4・レター）、大きさ（用紙に合わせる・実際の大きさ）、1 枚の用紙に 1 / 2 ページ、向き（自動・縦・横）、書き込みも印刷する
- プリンター、部数、両面は OS の印刷の画面で選ぶ
- 仕組み：保存するときと同じ PDF をメモリに組み（`compose_pdf`）、pdf.js で各ページを絵にして（150 dpi。50 ページを超えると 110 dpi、20 ページを超えると JPEG）、印刷のときだけ見える領域に用紙サイズのシートとして並べ、WebView の印刷を呼ぶ。表示だけの PDF は元の文書から直接描く。入力欄の値も印刷される
- 用紙の縁から 6 mm は空ける（プリンターが印刷できない範囲）

## 11. 日本語の文字

テキストボックスとフォームの文字は、パソコンの日本語フォントを PDF に埋め込む（使った文字だけ）。

| OS | フォント（見つかった最初のもの） |
|---|---|
| Windows | 游ゴシック、メイリオ、BIZ UD ゴシック、MS ゴシック |
| macOS | ヒラギノ角ゴシック W3、ヒラギノ角ゴ（GB）、Osaka |

画面のテキストボックスも同じフォントで描き、行の折り返しを画面と同じにする。見つからないときは Helvetica になり、日本語は書けない（設定画面に出る）。

## 12. 画面（0.2）

[UX.md](UX.md) §4〜§10 のとおり。ここには振る舞いだけ。

- **作業タブ**：ホーム（開く、保存 ｜ 元に戻す、やり直す ｜ 選択、マーカー、文字を置く、印鑑・画像 ｜ 検索）、書き込み（選択、マーカー、下線、取り消し線 ｜ 文字を置く、付箋、ペン、消しゴム ｜ 図形 ▾、印鑑・画像 ▾）、ページ（すべてのページを並べる ｜ 右に回転、左に回転、ページを削除 ｜ 白紙を足す、ファイルからページを足す ｜ ページを抜き出す、ページごとに分割）、入力と署名（選択、記入 ｜ チェック、バツ、黒丸、横線、日付 ｜ 署名 ▾）。文字と画像・保護・変換のタブは、その機能ができたときに足す（[ROADMAP.md](ROADMAP.md)）
- 道具は絵の下に言葉（高さ 56px）。幅が 1000px を切ると、絵の横に言葉（高さ 32px）
- ファイルを開くと「ホーム」。タブは覚えない
- **何をしますか**：作業タブの右端。打った言葉で操作を探す（名前と言い換え。カタカナとひらがな、全角と半角は同じ）。候補は 8 つまで、使えるものが先。Enter か クリックで実行し、その操作のあるタブに切り替わる
- **左の一覧**（F4）：ページ（上に回転・削除・足す）、書き込み、しおり
- **詳細**（右、幅 240px）：選んだ書き込みの設定とコメント、これから置くものの設定と「続けて置く」、左で選んだページの操作、何も選んでいなければ文書の情報（ファイル名、ページ数、いまのページの用紙、ファイルの大きさ、状態）。×で閉じられ、「表示 › 詳細」で戻せる。「すべてのページを並べる」のあいだは出ない
- **案内と状態**（下）：左に、いまの道具と次にすること、または選んでいるものとできること（`src/lib/hints.ts`）。「変更あり（保存していません）」「保存しました 10:32」。右にページ番号（打って Enter で移動）、表示の大きさ、回転して見る
- **使い方**（`src/components/HelpDialog.tsx`、F1、ホームの「使い方」、スタート画面、ヘルプメニュー）：1 画面 1 作業、3〜5 手順。開く・保存する、書き込む、印鑑・署名、入力欄の無い PDF に記入、ページを整理、印刷、困ったとき
- **初回の案内**（`src/components/Tips.tsx`）：1 度に 1 つ、全部で 3 つ。最初のファイルを開いたとき「上のタブで作業を選びます。まず『書き込み』を押してみてください」、最初に何かを変えたとき「ページの上のものはクリックで選べます」、最初に未保存になったとき「保存すると、元のファイルはそのまま残せます」。「わかった」で消え、`settings.json` の `seenTips` に記録して二度と出ない
- ズームとページ番号は下に置く。上の帯は編集の道具だけ
- **テーマ**：OS に合わせてライト / ダーク（[ADR-0002](../decisions/adr-0002-theme-follows-os.md)）。書き込みの色は変わらない
- **文字の大きさ**：設定で「ふつう / 大きく / もっと大きく」（1 倍 / 1.15 倍 / 1.3 倍）。画面の部品が全部大きくなる。PDF の表示の大きさは変わらない
- ウィンドウの最小は 960 × 600
