# Changelog

## 0.2.0

画面を「編集するためのもの」に作り直した版。入力と署名、印鑑、印刷、下書きが入った。

### 変更点

- 画面を作り直した。上に「ホーム・書き込み・ページ・入力と署名」の作業タブと、絵と言葉の付いたボタン。右の「詳細」で、選んだものの色や大きさ、コメントを変える。下の行に、いま何をしているかと次にすることの案内。ズームとページ番号は下に移した
- 画面の言葉を日常のものにした（注釈→書き込み、テキスト→文字を置く、スタンプ→印鑑、挿入→足す、書き出す→抜き出す、不透明度→濃さ）
- 右上の「何をしますか」に「ハンコ」「結合」「小さく」と打つと、合う操作が出る
- 色がパソコンの設定（ライト / ダーク）に合うようになった。文字を少し大きくし、設定で「大きく」「もっと大きく」にできる
- 初めて使うときに案内が 3 つ出る。F1（ホームの「使い方」）で、作業ごとの手順が読める
- 保存のとき、最初の 1 回は「新しいファイルとして保存」か「元のファイルに上書き」かを聞く
- 下書き：保存していない変更を 30 秒ごとに残す。アプリが急に終わっても、次の起動で「戻す」で続きから編集できる
- 入力と署名：入力欄の無い PDF に、記入・チェック・バツ・黒丸・横線・今日の日付を置ける。手書きの署名を作ってライブラリに入れ、どの PDF にも押せる
- 日付印と文字の印：部署・日付・名前の丸い印、「承認済み」「社外秘」などの印をその場で作って押せる。拡大してもきれいで、置いたあとも文字を直せる
- 印刷（Ctrl+P、Mac は ⌘P）：ページの範囲、用紙、用紙に合わせる、1 枚に 2 ページ、向き。プリンター・部数・両面はパソコンの印刷の画面で選ぶ
- 消しゴム：ペンで書いた線を、線ごとに消せる
- 回転して見る：画面の上だけで 90° 回す。ファイルは変わらない
- 開いたとき、画像だけの PDF や入力欄のある PDF には、そう知らせる
- 図形・文字・印鑑は 1 回置くと「選択」に戻る（「続けて置く」で戻らない）。Ctrl+D で書き込みを複製
- 左のページ一覧に「回転・削除・足す」のボタン

### ダウンロード

- Windows：`PDF_One_0.2.0_x64-setup.exe`
- macOS（Apple Silicon）：`PDF_One_0.2.0_aarch64.dmg`

### 注意

- 0.1.x を使っている場合は、アプリ内アップデートで入れ替わります（起動後に自動で確認します。すぐ確かめるならメニューの「アップデートを確認…」）
- 初めて入れる場合は、Apple や Microsoft の署名をしていないので、初回だけ警告が出ます。
  - Windows：`-setup.exe` を実行 → SmartScreen が出たら「詳細情報」→「実行」
  - macOS：`.dmg` を開いて「アプリケーション」へコピー → 起動すると「開発元を検証できない」と出るので「完了」→ **システム設定 › プライバシーとセキュリティ** の下にある「このまま開く」。ターミナルで `xattr -dr com.apple.quarantine "/Applications/PDF One.app"` でもよい
- 印刷は、この版で初めて入りました。印刷の画面が出ない、用紙の向きが違うなどあれば知らせてください（保存した PDF をほかのアプリで印刷することもできます）
- もとの文字の書き換え、保護された PDF の編集はまだできません（README「できないこと」）

## 0.1.2

### 変更点

- スクロールすると途中で黒い空白が出たり、ページが本来の位置からずれて飛んだりしていたのを直した（0.1.1 で直しきれていなかった）
- 速くスクロールしても、描き終わるまでは白いページが見えるようにした
- 画面から外れたページの絵のメモリをすぐ手放すようにした。ページの多い PDF でページが描かれなくなるのを防ぐ
- ページの整理を開いているあいだ、サイドバーのボタンが点いたままだったのを直した。整理画面でサイドバーのボタンを押すと、サイドバー付きの表示に戻る
- ページの整理やほかのタブから戻ったとき、「幅に合わせる」の倍率が変わらず、見ていた場所にそのまま戻るようにした
- ページの整理でサムネイルをダブルクリックすると、そのページが確実に開くようにした

## 0.1.0

最初の版（試用版）。PDF を見る・ページを整理する・書き込む・フォームに入力する。

### 変更点

- 開く：⌘O、ドロップ、「このアプリで開く」。タブで複数。最近使ったファイル
- 見る：幅に合わせる・ページ全体・拡大縮小、サムネイル、コメント一覧、しおり、文字の選択とコピー、リンク
- 検索：大文字小文字・全角半角・空白の違いを無視して探す
- ページの整理：並べ替え、回転、削除、白紙の挿入、別の PDF の挿入（結合）、書き出し（抽出）、分割
- 注釈：マーカー、下線、取り消し線、テキストボックス、付箋、ペン、四角形、楕円、直線、矢印、画像・印鑑（ライブラリ付き）。移動、大きさ、色、太さ、不透明度、コメント、複製
- フォーム入力：テキスト、チェック、ラジオ、選択
- 保存：別名の提案、上書き前のバックアップ。日本語はパソコンのフォントを埋め込むので、どのビューアでも同じに見える
- 元に戻す・やり直す、メニューバー、設定（作成者名、アップデートの自動確認）、ショートカット一覧、ログ、アプリ内アップデート
